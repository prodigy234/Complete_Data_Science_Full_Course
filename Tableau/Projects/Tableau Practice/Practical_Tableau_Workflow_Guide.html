Building Every Chart With the Practice Dataset
Companion to Tableau_Chart_Practice_Dataset.xlsx and Charts and Graphs in Tableau — A Comprehensive Reference Guide

1. About the Practice Dataset

Tableau_Chart_Practice_Dataset.xlsx contains five working data sheets, each purpose-built to support a specific set of charts, plus a Read Me sheet with a quick field guide. None of the five data sheets need to be joined together — each is used independently on its own worksheet in Tableau.

Orders

The core transactional table - 2,200 retail orders from 2023 to 2025 across Nigeria. This single sheet drives the large majority of charts in this guide.

  • Order IDUnique identifier for each order line
  • Order DateDate the order was placed (2023-2025)
  • Ship DateDate the order was shipped
  • Ship ModeStandard Class, Second Class, First Class, or Same Day
  • Customer ID / Customer NameUnique customer identifier and name
  • SegmentConsumer, Corporate, or Home Office
  • Country / State / CityGeographic location of the order (real Nigerian states and cities)
  • RegionBusiness zone: North, South, East, West, or Central
  • Latitude / LongitudeGeocoordinates of the City, used for Symbol Maps
  • Category / Sub-CategoryProduct hierarchy: Furniture, Office Supplies, Technology and their sub-categories
  • Product NameSpecific product ordered
  • QuantityUnits ordered
  • Unit PricePrice per unit before discount
  • DiscountDiscount rate applied (0% to 30%)
  • SalesNet sales value for the line (after discount)
  • ProfitProfit for the line (can be negative on heavily discounted orders)

Sales_Targets

Monthly Target Sales vs Actual Sales by Region for 2025 - purpose-built for the Bullet Graph.

  • RegionNorth, South, East, West, or Central
  • Month Date / Month LabelCalendar month for the target/actual pair
  • Target SalesThe sales goal set for that region and month
  • Actual SalesWhat was actually achieved

Project_Tasks

16 tasks describing a sample Tableau dashboard-build project, from Data Connection through Training & Handover - purpose-built for the Gantt Chart.

  • Task ID / Task NameIdentifier and name of each project task
  • PhaseDiscovery, Design, Build, Assembly, Testing, or Launch
  • Start Date / End DatePlanned start and end date of the task
  • Duration (Days)Calculated span of the task in days
  • OwnerPerson or team responsible
  • Percent CompleteProgress indicator (0-100)

Sales_Funnel

Monthly pipeline stage counts (Leads through Closed Won) by Region for 2025 - purpose-built for the Funnel Chart.

  • RegionNorth, South, East, West, or Central
  • Month LabelCalendar month of the pipeline snapshot
  • Stage / Stage OrderLeads, Qualified, Proposal, Negotiation, Closed Won, and their sequence number 1-5
  • Lead CountNumber of leads/deals at that stage

Quarterly_Bridge

A starting sales value, a sequence of named increases and decreases, and an ending value - purpose-built for the Waterfall Chart.

  • LabelName of the step, e.g. '2025 Q4 Starting Sales', 'New Customer Wins'
  • Change TypeStart, Increase, Decrease, or Total
  • Step OrderSequence number controlling left-to-right order
  • ValueThe amount of the change (negative for decreases)

2. Connecting the Data in Tableau

Follow these steps once, at the start of your workbook, to get every sheet ready to use.

  1. Open Tableau Desktop or Tableau Public.
  2. Under Connect on the start screen, choose Microsoft Excel, then browse to and select Tableau_Chart_Practice_Dataset.xlsx.
  3. You will land on the Data Source screen with all six sheets (Read Me, Orders, Sales_Targets, Project_Tasks, Sales_Funnel, Quarterly_Bridge) listed on the left under Sheets.
  4. Drag Orders onto the canvas first - this is the table you will use for the majority of charts, and it does not need to be joined to anything else.
  5. Do not join Sales_Targets, Project_Tasks, Sales_Funnel, or Quarterly_Bridge to Orders or to each other. Each is designed to be used on its own worksheet for its specific chart type (Bullet Graph, Gantt, Funnel, Waterfall respectively) - joining them would create incorrect row multiplication.
  6. Check the data preview at the bottom of the Data Source screen: confirm Order Date and Ship Date show a calendar icon (Date type), and Sales, Profit, Quantity, Discount, Unit Price show a number icon (Number type).
  7. Right-click the State field in the Data pane (once on a worksheet) and confirm Geographic Role is set to State/Province. Do the same for City, confirming it is set to City. Tableau should auto-detect both correctly since these are real Nigerian place names.
  8. Leave the connection as Live for practice purposes (no need to create an Extract) - Live queries the Excel file directly every time you change the view, which is simplest while learning.
  9. Click the Sheet 1 tab at the bottom to leave the Data Source screen and start building worksheets. When you need a different table (e.g. Sales_Targets for the Bullet Graph), open a New Worksheet and drag that table's fields in - Tableau will let you use whichever table you last dragged onto the canvas, so add each new table to the canvas the first time you need it.

3. Step-by-Step Workflow for Every Chart

Each chart states exactly which sheet to use, the precise fields and shelves to drag them onto, and the one rule that matters most. Build each on its own worksheet, and rename the tab to match the chart title as you go.

1. Vertical Bar Chart - Sales by Region

Orders
  1. Drag Region to the Columns shelf.
  2. Drag Sales to the Rows shelf. Tableau builds a vertical bar chart, SUM(Sales) per region.
  3. Click the Sort toolbar icon to rank bars descending.
  4. Drag Sales onto Label on the Marks card to show exact values.
Key rule: Keep the axis starting at zero; do not truncate it.

2. Horizontal Bar Chart - Top Products by Sales

Orders
  1. Drag Product Name to the Rows shelf.
  2. Drag Sales to the Columns shelf.
  3. Sort descending, then right-click Product Name > Filter, and use a Top filter (By field, Top 10, by Sales) to keep the list readable.
  4. Drag Sales onto Label.
Key rule: Always sort a ranked list, largest at top.

3. Stacked Bar Chart - Sales by Region and Category

Orders
  1. Drag Region to Columns and Sales to Rows.
  2. Drag Category onto Color on the Marks card - Tableau stacks each region's bar into Furniture / Office Supplies / Technology segments.
  3. Drag Category onto Label as well to label each segment.
Key rule: Limit the stacking field to a small number of members (Category has only 3, which is ideal).

4. Side-by-Side Bar Chart - Segment Performance by Region

Orders
  1. Drag Region to Columns.
  2. Drag Segment to Columns as well, placed to the right of Region.
  3. Drag Sales to Rows.
  4. Drag Segment onto Color.
Key rule: Keep the secondary field (Segment, 3 members) small so bars stay readable.

5. Line Chart - Sales Trend Over Time

Orders
  1. Drag Order Date to Columns, then change its pill to the continuous (green) Month.
  2. Drag Sales to Rows.
  3. Drag Region onto Color to compare five trend lines at once.
  4. Optional: Analytics pane > Trend Line for a fitted trend per region.
Key rule: Always use the continuous (green) date field, never the discrete (blue) one, for a true timeline.

6. Area Chart - Cumulative Sales Composition Over Time

Orders
  1. Build the line chart above, then change the Marks card type to Area.
  2. Drag Category onto Color to stack Furniture / Office Supplies / Technology as bands over time.
Key rule: Only stack when the combined total is itself meaningful.

7. Pie Chart - Share of Sales by Category

Orders
  1. Drag Category to Color on the Marks card.
  2. Drag Sales to Angle.
  3. Set the Marks card type to Pie.
  4. Drag Sales to Label, then right-click the label pill > Quick Table Calculation > Percent of Total.
Key rule: Category has only 3 members - ideal for a pie chart; never do this with Sub-Category (12 members).

8. Donut Chart - Share of Sales with a Center KPI

Orders
  1. Build the pie chart above on one axis.
  2. Create a calculated field Dummy = MIN(0), place it on a second, dual-axis Rows position with Marks type Pie and no Color, sized smaller than the outer pie.
  3. Right-click the second axis > Dual Axis, then Synchronize Axis.
  4. Add a text label in the centre showing SUM(Sales) formatted large, e.g. as a title or annotation.
Key rule: Use the hollow centre purposefully - display the grand total there.

9. Scatter Plot - Sales vs Profit by Order

Orders
  1. Drag Sales to Columns and Profit to Rows.
  2. Turn off Analysis > Aggregate Measures so each order plots individually.
  3. Drag Order ID to Detail on the Marks card.
  4. Set Marks card type to Circle.
  5. Analytics pane > Average Line on both axes to divide the view into quadrants.
Key rule: Disaggregate the measures - the point is to see individual orders, not a single summary dot.

10. Bubble Chart - Sales, Profit, and Quantity Together

Orders
  1. Build the scatter plot above.
  2. Drag Quantity onto Size on the Marks card.
  3. Drag Category onto Color.
  4. Lower mark opacity to about 75% (Color menu) so overlapping bubbles stay visible.
Key rule: Never encode more than 4 variables (x, y, size, colour) at once.

11. Treemap - Sales by Sub-Category

Orders
  1. Drag Sub-Category to Color on the Marks card.
  2. Drag Sales to Size.
  3. Set Marks card type to Square, or select Sub-Category + Sales together and choose Show Me > Treemap.
  4. Drag Sub-Category to Label.
  5. Optional: create Profit Ratio = SUM([Profit])/SUM([Sales]) and drag it onto Color instead of Sub-Category, for a second-metric encoding.
Key rule: Use Size for magnitude and Color for a different metric, not the same one twice.

12. Heat Map - Order Volume by Region and Month

Orders
  1. Drag Order Date (continuous Month) to Columns.
  2. Drag Region to Rows.
  3. Drag Order ID onto Color and set its aggregation to Count Distinct (CNTD).
  4. Set Marks card type to Square.
Key rule: Use a sequential palette since order count is always positive (one direction).

13. Highlight Table - Sales by Region and Category

Orders
  1. Drag Category to Columns and Region to Rows.
  2. Drag Sales to Text on the Marks card.
  3. Drag Sales to Color as well.
  4. Or select Region, Category, and Sales together and choose Show Me > Highlight Table directly.
Key rule: The same measure (Sales) drives both the number shown and the shading - keep them consistent.

14. Text Table / Crosstab - Full Detail Report

Orders
  1. Drag Region and then Category to Rows.
  2. Drag Sales, Profit, and Quantity together onto Text (this creates Measure Names/Measure Values automatically).
  3. Analysis menu > Totals > Show Row Grand Totals for a summary row.
  4. Format > Numbers to set consistent currency and decimal formatting.
Key rule: Right-align numbers, left-align text, and keep decimal places consistent throughout.

15. Box-and-Whisker Plot - Profit Distribution by Category

Orders
  1. Drag Category to Columns.
  2. Drag Profit to Rows and turn off Aggregate Measures.
  3. Drag Order ID to Detail.
  4. Select Show Me > Box-and-Whisker Plot, or drag Box Plot from the Analytics pane onto the view.
Key rule: Never pre-aggregate Profit before building this chart - the distribution of individual orders is the whole point.

16. Bullet Graph - Actual vs Target Sales by Region

Sales_Targets
  1. Drag Region to Rows.
  2. Drag Actual Sales to Columns, Marks type Bar.
  3. Select Actual Sales and Target Sales together in the Data pane, then choose Show Me > Bullet Graph, which places Target Sales as the reference tick automatically.
  4. Drag Month Label to Filters if you want to focus on a single month, or leave all 12 months for a Region x Month grid.
Key rule: Use this sheet, not Orders - it already contains the Target vs Actual pairing needed.

17. Gantt Chart - Dashboard Build Project Timeline

Project_Tasks
  1. Drag Start Date to Columns (keep it continuous).
  2. Drag Task Name to Rows - sort rows by Start Date for a natural top-to-bottom timeline.
  3. Set Marks card type to Gantt Bar.
  4. Drag Duration (Days) onto Size to set each bar's length.
  5. Drag Phase onto Color to distinguish Discovery / Design / Build / Assembly / Testing / Launch.
  6. Drag Owner and Percent Complete to Tooltip for on-hover detail.
Key rule: Sort rows by Start Date (or task sequence), not alphabetically, so the timeline reads naturally.

18. Histogram - Distribution of Order Quantity

Orders
  1. Select the Quantity field in the Data pane.
  2. Choose Show Me > Histogram - Tableau automatically creates a Quantity (bin) field and builds the chart.
  3. Right-click the new bin field > Edit, and try a couple of different bin sizes to see how the shape changes.
Key rule: Pick a bin size that shows the shape clearly - not so wide it flattens it, not so narrow it becomes noisy.

19. Dual-Axis / Combo Chart - Sales and Profit by Month

Orders
  1. Build a bar chart: continuous Month of Order Date on Columns, Sales on Rows.
  2. Drag Profit to the far right of the view to create a second axis.
  3. Right-click the new axis > Dual Axis.
  4. Change the second Marks card (Profit) to Line, and colour it differently from the Sales bars.
  5. Right-click either axis and title it clearly, e.g. 'Sales (bars, left) and Profit (line, right)'.
Key rule: Always label which axis belongs to which measure - never leave two unlabelled scales side by side.

20. Packed Bubble Chart - Sales by Customer

Orders
  1. Drag Customer Name to Detail on the Marks card.
  2. Drag Sales to Size.
  3. Set Marks card type to Circle, or select Customer Name + Sales and choose Show Me > Packed Bubbles.
  4. Drag Segment onto Color, and Customer Name onto Label.
  5. Add a Top N filter (Top 40 by Sales) so the view stays legible with 160 customers in the data.
Key rule: Filter to a manageable number of bubbles (under ~40-50) before presenting.

21. Waterfall Chart - Q4 to Q1 Sales Bridge

Quarterly_Bridge
  1. Drag Label to Columns, sorted by Step Order (right-click Label > Sort > by Step Order field, ascending).
  2. Drag Value to Rows.
  3. Set Marks card type to Gantt Bar.
  4. Right-click the Value pill on Rows > Add Table Calculation > Running Total, computed along Label, to position each bar.
  5. Create a calculated field for bar size (the absolute step Value) and drop it on Size.
  6. Drag Change Type onto Color to distinguish Start / Increase / Decrease / Total.
Key rule: Order steps by Step Order, never alphabetically - a waterfall's story depends entirely on sequence.

22. Funnel Chart - Lead Conversion by Stage

Sales_Funnel
  1. Drag Stage to Rows, sorted by Stage Order (right-click Stage > Sort > by Stage Order field, ascending).
  2. Drag Lead Count to Columns, aggregated as SUM.
  3. Create a calculated field to centre the bars, e.g. Centered = -SUM([Lead Count])/2, and place it on a dual axis alongside Lead Count, or simply build the horizontal bar and centre it via Format > Alignment for a simpler version.
  4. Drag Region or Month Label to Filters to focus on one slice of the funnel at a time.
  5. Add SUM(Lead Count) to Label to show the raw count at each stage.
Key rule: Always keep stages in true process order (Leads to Closed Won), driven by Stage Order, not alphabetically.

23. Symbol Map - Sales by City

Orders
  1. Double-click City in the Data pane. Tableau automatically generates Latitude and Longitude and plots a map.
  2. Drag Sales onto Size on the Marks card.
  3. Drag Region onto Color.
  4. Drag City and Sales to Tooltip for on-hover detail.
Key rule: Confirm City's Geographic Role is set correctly before relying on the auto-generated coordinates.

24. Filled Map - Profit by State

Orders
  1. Double-click State in the Data pane.
  2. Change the Marks card type to Map (Filled Map / Polygon).
  3. Drag Profit onto Color - choose a diverging palette since profit can be negative.
  4. Drag State and Profit to Tooltip.
Key rule: Use a diverging colour palette for Profit since it can be negative or positive.

25. Sparklines - Compact Trend per Region

Orders
  1. Drag Region to Rows.
  2. Drag Order Date (continuous Month) to Columns.
  3. Drag Sales to Rows (as a second field, or keep it on the Marks card so a line draws per region).
  4. Set Marks card type to Line.
  5. Right-click each axis and uncheck Show Header; Format > Lines and remove gridlines for a clean, compact sparkline look.
Key rule: Pair each sparkline with at least one number label - shape alone does not communicate magnitude.

4. Assembling a Dashboard

Once you have built several worksheets, combine them into an interactive dashboard.

  1. Right-click the sheet tabs at the bottom and choose New Dashboard.
  2. Set the dashboard Size (e.g. Automatic, or a fixed 1200x800 for consistent presentation).
  3. Drag two or three finished worksheets from the Sheets list on the left onto the dashboard canvas (e.g. the Bar Chart, the Line Chart, and the Filled Map).
  4. Use Layout Containers (drag a Horizontal or Vertical container from the Objects list) to arrange worksheets neatly in rows or columns.
  5. Add a Filter Action: Dashboard menu > Actions > Add Action > Filter, so clicking a bar in one chart filters the others.
  6. Add a Text object as a title, and a Legend/Filter object if you want viewers to control Region or Category interactively.
  7. Use Dashboard > Format to adjust fonts, borders, and background shading consistently with the rest of the guide's formatting rules.

5. Saving and Publishing Your Work

  1. File > Save As to save your workbook (.twb or .twbx). Choose Save as Packaged Workbook (.twbx) if you want the Excel data embedded inside the file for easy sharing.
  2. If using Tableau Public, click the Save button in the top-left (the icon showing a save/upload arrow) to publish your workbook to your Tableau Public profile - this requires a free Tableau Public account and an internet connection.
  3. If using Tableau Desktop with Tableau Server/Online access, use Server > Publish Workbook instead.
  4. Before publishing, double check every worksheet has a clear title, and that filters/legends you want visible to viewers are shown (right-click the field > Show Filter / Show Legend).
