1. Connecting Tableau to the Data

This is the very first practical step inside Tableau Desktop or Tableau Public, before any chart can be built.

1Open Tableau Desktop and, on the start screen, click Text File under the Connect panel on the left side.
2Browse to and select staff_dataset.csv. Tableau will load the file into the Data Source tab and show a preview grid of the data.
3Look at the top left corner of the Data Source tab. If Tableau shows a banner saying "Data Interpreter has detected possible extra data," you can leave it switched off for this file, since the dataset is already a clean single grid with one header row and no extra title rows or subtotal rows above the data.
4Check every column header at the top of the preview grid. Tableau assigns a data type icon (Abc for text, a hash symbol for number, a calendar for date) to each field automatically. Click each header's data type icon and confirm the following corrected types:
  • Staff_id should be a Number (Integer). Even though it is being repurposed as a transaction identifier rather than a staff identifier, it should stay numeric so that it can still be counted, but it will never be summed.
  • Amount, Customers, and Boxes should be Number (Integer).
  • Full_Name, Country, and Product should be String.
  • Date will most likely be auto detected as a String because it does not match Tableau's default date parsing pattern. This will be corrected using a calculated field rather than forcing the raw field, see Section 2 below for the exact reason why.
  • Average_Amount should be Number (Decimal), but as explained in Section 2, this field will not be used directly anywhere in the dashboards.
5Rename the connection at the top of the Data Source tab from the default file name to something descriptive, for example Chocolate Sales Data, so that anyone opening the workbook later immediately understands what the source contains.
6Decide between a Live connection and an Extract. For a CSV file of this size (3,791 rows), select Extract in the top right of the Data Source tab, then click Add, keep the default full extract, and click Save. An extract will make every chart in this project noticeably faster to render and filter, since Tableau converts the file into its own optimised .hyper storage format rather than re-reading the raw CSV on every single interaction.
7Click the sheet tab (labelled Sheet 1) at the bottom left to move from the Data Source tab into an actual worksheet, where the calculated fields from Section 3 will be built next.
Since this project uses a single flat table, there is no join, blend, or relationship step required at this stage. If a second table (such as a staff directory or a currency exchange rate table) is added later, it would be attached here on the Data Source tab using Tableau's relationship canvas, matched on Full_Name or Country respectively.

2. Solutions to Every Data Problem

Each problem identified in the planning document is resolved below, in the same order it was raised, with the exact fix and the reasoning behind it.

SolvedProblem 1: Staff_id is mislabelled as a staff identifier

Solution: Right click Staff_id in the Data pane and choose Rename. Rename it to Transaction ID. This does not change any values, it only relabels the field so nobody on the team mistakes it for a count of staff. From this point forward, any question about "how many sales representatives" or "which representative sold the most" must use Full_Name (or its cleaned version below), never Transaction ID.

SolvedProblem 2: Full_Name has a double space on every row

Solution: Create a new calculated field named Clean Full Name that collapses any run of multiple spaces down to a single space and trims the ends. Right click in the Data pane, choose Create Calculated Field, name it Clean Full Name, and enter:

TRIM(REGEXP_REPLACE([Full_Name], "\s+", " "))

This single formula fixes all 3,791 rows in one pass, including the two names that contain apostrophes (Marney O'Breen and Wilone O'Kielt), since the regular expression only targets whitespace characters and leaves every other character untouched. From this point forward, Clean Full Name replaces Full_Name in every single chart, filter, and calculation in this project.

SolvedProblem 3: Date is stored as text in day/month/year format

Solution: Create a new calculated field named Order Date that explicitly parses the text using the correct day first pattern rather than relying on Tableau's default guess:

DATE(DATEPARSE("dd/MM/yyyy", [Date]))

Once this field is created, right click it in the Data pane and confirm its data type icon shows a calendar (Date), then drag it into the view at least once and confirm the very first value renders as 1 January 2021 and not 1 January 2021 misread as month 1, day 1 (which happens to look the same for the first day of the month, so also spot check a value like row 300 or later where day and month clearly differ, for example a raw value of 15/03/2021 should render as 15 March 2021, not the 3rd of some other month). Once confirmed correct, right click Order Date and choose Default Properties then Date Format to standardise how it displays across every chart.

SolvedProblem 4: The final month (January 2022) has an unusually high row count

Solution: This is not a formula fix, it is a presentation and communication fix. Two options are available and both are implemented in this project:

  • On every monthly trend chart, a caption text box is added directly on the dashboard stating: "Note: January 2022 reflects a partial or differently sized reporting period compared to prior months and should be read with that context in mind."
  • A quick filter action lets the viewer optionally exclude the final month from the trend line entirely, so like for like monthly comparisons are still possible using the full 2021 calendar year on its own.

SolvedProblem 5: Two transactions have zero Amount and zero Boxes

Solution: Rather than silently deleting these two rows, a calculated field named Data Quality Flag is created so they remain visible and traceable but excludable on demand:

IF [Amount] = 0 AND [Boxes] = 0 THEN "Zero Value Transaction" ELSE "Valid Transaction" END

This field is added to a filter shelf across every worksheet (or set as a context filter at the data source level once confirmed with the client) so that headline totals can be shown either including or excluding these two rows, with the choice made deliberately rather than by accident.

SolvedProblem 6: Country field mixes a full country name style with one abbreviation ("UK")

Solution: A calculated field named Country Display Name standardises the label for presentation without altering the original field, which is kept intact for any future join back to other systems that may already use "UK" as their standard code:

IF [Country] = "UK" THEN "United Kingdom" ELSE [Country] END

Country Display Name is used on every chart title, axis, and tooltip, while the original Country field remains available in the Data pane for technical use.

SolvedProblem 7: No product category grouping exists above the 22 individual products

Solution: A Tableau Group is created directly on the Product field. In the Data pane, right click Product, choose Create then Group, and manually combine the 22 products into broader families, for example grouping "85% Dark Bars", "70% Dark Bites", "50% Dark Bites", and "99% Dark and Pure" under a single "Dark Chocolate" family, grouping "White Choc" and "Milk Bars" under "Milk and White Chocolate", and so on for the remaining products. The resulting field is named Product Category and is used wherever a simplified, less cluttered product view is needed, while the original 22 product names remain available for detailed drill down.

SolvedProblem 8: Average_Amount is a broken, constant field (5,724.54 on every row)

Solution: This field is hidden from the workbook entirely (right click it in the Data pane and choose Hide) so nobody accidentally drags it into a chart. In its place, three genuine calculated measures are built fresh, guaranteed to change correctly whenever the level of detail in a chart changes:

Average Price per Box: SUM([Amount]) / SUM([Boxes]) Average Sale per Transaction: AVG([Amount]) Revenue per Customer: SUM([Amount]) / SUM([Customers])

Because these are written as aggregations rather than hardcoded numbers, each one automatically recalculates correctly whether the chart is sliced by representative, by product, by country, or by month, which is exactly the behaviour the original broken field could never deliver.

SolvedProblem 9: Customers field definition was not documented

Solution: For this project, Customers is documented and labelled on every relevant chart tooltip as "Customers reached in this transaction record," and the Revenue per Customer measure built above is explicitly subtitled "based on the Customers field as recorded in the source data" wherever it appears, so viewers are never given a false sense of precision about what is being measured.

4. Dashboard 1: Executive Sales Overview

Purpose

A single landing view giving senior stakeholders total business performance at a glance, before drilling into representative, product, or geography detail on the other three dashboards.

Chart 1: KPI Summary Tiles

1Create four new worksheets named KPI - Total Sales, KPI - Total Boxes, KPI - Avg Price per Box, and KPI - Revenue per Customer.
2On each sheet, drag the relevant measure (Total Sales Amount, Total Boxes Sold, Average Price per Box, Revenue per Customer) onto the Text shelf on the Marks card.
3Change the Mark type to Text if it is not already.
4Select the number on the view, increase the font size to around 36pt using the toolbar, and add a bold label above it (double click the sheet title and type the KPI name, for example "Total Sales Amount").
5Remove all gridlines, axis lines, and row and column dividers under Format then Borders and Lines so each tile shows only the clean number and its label.

Chart 2: Sales Trend Over Time

1Create a new worksheet named Sales Trend Over Time.
2Drag Order Date onto the Columns shelf. Right click the resulting field and set it to the continuous Month level (shown in green, not the default discrete blue pill), so the line renders as one continuous timeline from January 2021 through January 2022.
3Drag Total Sales Amount onto the Rows shelf.
4Change the Mark type to Line.
5Right click the Order Date axis and choose Add Reference Line if an average line is wanted for context, or skip this if a clean single trend line is preferred.
6Add a caption text object beneath the chart on the dashboard noting the partial final month, as agreed in the Section 2 solution for that issue.

Chart 3: Sales by Country

1Create a new worksheet named Sales by Country.
2Drag Country Display Name onto the Rows shelf.
3Drag Total Sales Amount onto the Columns shelf.
4Change Mark type to Bar.
5Click the Sort descending icon in the toolbar so the highest selling country appears at the top.
6Drag Total Sales Amount onto the Label shelf on the Marks card so each bar shows its exact value.
7Drag Country Display Name onto the Color shelf for a distinct colour per country bar.

Chart 4: Top 10 Products by Sales Amount

1Create a new worksheet named Top 10 Products.
2Drag Product onto Rows and Total Sales Amount onto Columns, Mark type Bar, sorted descending exactly as in Chart 3.
3Right click Product on the Rows shelf, choose Filter, switch to the Top tab, select By field, set it to Top 10 By Total Sales Amount, then click OK.

Assembling Dashboard 1

1Create a new Dashboard, name it Executive Sales Overview, and set the size to Automatic or a fixed desktop size such as 1300 by 900 pixels.
2Drag the four KPI tile sheets into a horizontal row across the top of the dashboard canvas, resizing each to an equal width.
3Drag Sales Trend Over Time beneath the KPI row, spanning the full width.
4Below the trend chart, place Sales by Country on the left half and Top 10 Products on the right half, side by side.
5Add a dashboard title text object at the very top reading "Executive Sales Overview - Chocolate Sales Performance."

5. Dashboard 2: Sales Representative Performance

Purpose

Compares and ranks the 25 sales representatives so sales management can identify top and bottom performers and coach accordingly.

Chart 1: Sales by Representative

1New worksheet Sales by Representative. Drag Clean Full Name onto Rows, Total Sales Amount onto Columns, Mark type Bar, sort descending.
2Drag Total Sales Amount onto Color and apply a sequential gold to brown colour gradient to visually reinforce ranking.

Chart 2: Representative Leaderboard

1New worksheet Representative Leaderboard. Drag Sales Rep Rank onto Rows first, then Clean Full Name onto Rows beside it.
2Drag Total Sales Amount, Total Boxes Sold, and Average Sale per Transaction onto the Text shelf in that order to build a multi column crosstab.
3Change the Mark type to Automatic or Text so the result displays as a clean ranked table.
4Right click Sales Rep Rank on Rows and confirm its table calculation is computed using Clean Full Name as the addressing field, so the rank recalculates correctly if filters are later applied.

Chart 3: Boxes Sold versus Sales Amount

1New worksheet Boxes vs Amount by Rep. Drag Total Boxes Sold onto Columns and Total Sales Amount onto Rows.
2Drag Clean Full Name onto Detail on the Marks card, and change Mark type to Circle.
3Drag a measure such as the count of Customers summed onto the Size shelf so each bubble reflects the volume of customers reached by that representative.
4Drag Clean Full Name onto Color for a distinct colour per representative, and onto Label if names should show directly on the chart.

Chart 4: Representative Trend Over Time

1New worksheet Rep Trend Over Time. Drag continuous Order Date (Month level) onto Columns, Total Sales Amount onto Rows, Mark type Line.
2Drag Clean Full Name onto Color so one line is drawn per representative.
3Because 25 lines on one chart is visually busy, add Clean Full Name to the Filters shelf and set up a Top N filter (Top 5 by Total Sales Amount) so the trend chart focuses on the leading representatives by default, while the full list stays available if the filter is cleared through a dashboard control.

Assembling Dashboard 2

1New Dashboard named Sales Representative Performance.
2Place Sales by Representative on the left side, full height.
3Stack Representative Leaderboard above Boxes vs Amount by Rep on the right side, and place Rep Trend Over Time beneath both, spanning the full width.
4Add a dashboard action (see Section 8) so clicking a bar in Sales by Representative filters all other sheets on this dashboard to that one representative.

6. Dashboard 3: Product Performance Analysis

Purpose

Identifies which chocolate products drive the most revenue and volume, and which are most and least efficient per box sold.

Chart 1: Sales by Product

1New worksheet Sales by Product. Drag Product onto Rows, Total Sales Amount onto Columns, Mark type Bar, sort descending, all 22 products shown.

Chart 2: Average Price per Box by Product

1New worksheet Avg Price per Box by Product. Drag Product onto Rows, Average Price per Box onto Columns, Mark type Bar, sort descending.
2This chart directly replaces the broken Average_Amount field described in Section 2, and every bar here will genuinely differ in height because it is calculated per product rather than fixed at one repeated number.

Chart 3: Product Sales Trend Over Time

1New worksheet Product Trend Over Time. Drag continuous Order Date (Month) onto Columns, Total Sales Amount onto Rows, Mark type Line, Product onto Color.
2Apply a Top N filter on Product (Top 5 by Total Sales Amount) so the trend lines stay legible rather than showing all 22 products at once.

Chart 4: Product Mix by Country

1New worksheet Product Mix by Country. Drag Country Display Name onto Rows and Product Category onto Columns.
2Drag Total Sales Amount onto the Color shelf on the Marks card, and change Mark type to Square to build a highlight table (heat map) style view.
3Drag Total Sales Amount onto Label as well, so each cell shows both a colour intensity and the exact figure.

Assembling Dashboard 3

1New Dashboard named Product Performance Analysis.
2Place Sales by Product and Avg Price per Box by Product side by side across the top half.
3Place Product Trend Over Time and Product Mix by Country side by side across the bottom half.

7. Dashboard 4: Geography and Seasonality

Purpose

Shows where in the world sales are strongest and how sales activity rises and falls across the calendar.

Chart 1: World Map by Country

1New worksheet Sales Map. Double click Country Display Name in the Data pane. Tableau will automatically generate a filled map, since all six country names are recognised geographic values.
2Drag Total Sales Amount onto the Color shelf, and also onto the Size shelf if a bubble map style is preferred over a filled polygon map (change Mark type to Circle for the bubble style, or leave it as Map/Filled Map for the polygon style).
3Drag Total Sales Amount and Total Boxes Sold onto Tooltip so hovering over each country shows both figures.

Chart 2: Monthly Trend Line with Trend Analysis

1New worksheet Monthly Trend with Trend Line. Build the same way as Dashboard 1's Sales Trend Over Time chart (continuous Month on Columns, Total Sales Amount on Rows, Mark type Line).
2From the Analytics pane on the left, drag a Trend Line object onto the chart and drop it on the Linear option to overlay a statistical trend line on top of the actual monthly data.

Chart 3: Seasonality Heat Map

1New worksheet Seasonality Heat Map. Drag Order Date onto Columns and set it to discrete Year. Drag Order Date again onto Rows and set that second copy to discrete Month (the month name only, not year plus month).
2Drag Total Sales Amount onto the Color shelf, change Mark type to Square, and apply a sequential colour palette so darker or more intense cells represent higher sales months.

Chart 4: Quarter Comparison

1New worksheet Quarter Comparison. Drag discrete Order Date set to Quarter onto Columns, Total Sales Amount onto Rows, Mark type Bar.
2Drag discrete Order Date set to Year onto the Color shelf so 2021 and 2022 quarters are visually distinguished, keeping in mind 2022 will only ever show a Q1 bar built from partial data, which should carry the same caption note used in Dashboard 1.

Assembling Dashboard 4

1New Dashboard named Geography and Seasonality.
2Place Sales Map across the top, spanning the full width for maximum visual impact.
3Place Monthly Trend with Trend Line and Seasonality Heat Map side by side beneath the map.
4Place Quarter Comparison along the bottom, spanning the full width.

8. Filters, Actions, and Parameters

Global filters

  • Drag Country Display Name, Product, and Order Date onto every dashboard as quick filters, then right click each filter and choose Apply to Worksheets then All Using This Data Source, so one filter selection updates every dashboard in the workbook consistently.
  • Add Data Quality Flag as a filter defaulted to "Valid Transaction" on every dashboard, with the option for a viewer to switch it to show all records including the two zero value rows.

Dashboard actions

  • On Dashboard 2, add a Filter action (Dashboard menu then Actions then Add Action then Filter) that runs on Select, sourced from Sales by Representative, targeting the other three sheets on that same dashboard, so clicking one representative's bar filters the leaderboard, scatter plot, and trend line to that individual.
  • On Dashboard 4, add a Highlight action sourced from the Sales Map so hovering over a country highlights that country's marks across the other sheets on the same dashboard without fully filtering them out.
  • If a fifth navigation landing page is built, add Navigate actions (Go to Sheet) on four large button style objects so a single click moves the viewer to each of the four dashboards.

Parameters

  • Create a parameter named Top N Selector with an integer range (for example 3 to 10) and use it inside the Top N filters on the Product and Representative trend charts, so a viewer can adjust how many lines are shown live on the dashboard rather than that number being fixed at build time.

9. Formatting, Theming, and Publishing

Colour and font theme

  • Use a chocolate inspired palette consistently: dark brown for headers and titles, warm gold for accents and highlights, cream or off white for backgrounds, so the visual identity matches the subject matter of the dataset.
  • Set one consistent font family (for example Tableau's built in "Tableau Book" or a clean sans serif such as Segoe UI) across every worksheet through Format then Workbook so headings, labels, and tooltips all match.

Tooltips

  • Edit every worksheet's tooltip (the small pencil icon on the Tooltip shelf) to remove default technical field names and replace them with clear, client friendly sentences, for example "This representative generated (Total Sales Amount) across (Total Boxes Sold) boxes."

Publishing

1Once all four dashboards are complete and tested, go to Server then Publish Workbook if using Tableau Server or Tableau Cloud, or File then Save to Tableau Public if the project is being shared publicly.
2Before publishing, choose which sheets are shown to viewers (uncheck any hidden helper worksheets that only exist to feed a dashboard) and set the default starting dashboard, typically Executive Sales Overview.
3Confirm the extract refresh schedule if published to a server, or note that a manual re-publish will be required if the source CSV changes, since Tableau Public does not support automatic scheduled refreshes.
