Introduction and Dataset Overview

This guide teaches Excel Pivot Tables and Pivot Charts using a single, realistic dataset built for Prodigy Retail & Electronics Ltd, a fictional Nigerian retail company selling Electronics, Home Appliances, Phones and Tablets, Computing equipment, Furniture, and Fashion and Accessories.

The dataset covers 1,100 sales transactions recorded between January 2023 and December 2025, across six regions of Nigeria (South West, South East, South South, North Central, North West, and North East), 16 sales representatives, and 27 distinct products.

Companion files: Prodigy_Pivot_Tables_Practice_Workbook.xlsx (raw dataset and blank working sheets), Prodigy_Pivot_Tables_Companion_Notebook.ipynb (pandas answer key), and Prodigy_Excel_Pivot_Tables_Training_Guide.docx (this same content as a printable Word document).

Pivot Table basics:

  1. A Pivot Table summarizes a large table of data by letting you drag fields into four areas: Rows, Columns, Values, and Filters.
  2. Fields placed in Values are automatically summarized (Sum for numbers, Count for text) but the summary type can be changed through Value Field Settings.
  3. A Pivot Chart is a chart built directly from a Pivot Table, and updates automatically when the Pivot Table changes.
  4. Whenever the source data changes, right-click any Pivot Table and choose Refresh, or click Refresh All on the Data tab.
Pivot Table 1

Total Net Sales by Region

Shows how total revenue is distributed across the six regions Prodigy Retail & Electronics Ltd sells in, so management can see which regions are driving the business.

Field Layout

RowsRegion
Columns(none)
Filter(none)
ValuesSum of Net Sales (NGN)

Step-by-Step Instructions

  1. Click any cell inside the Sales Data table (RetailSalesTable) on the Sales Data sheet.
  2. Go to the Insert tab and click PivotTable. Confirm the table range is correct and choose New Worksheet, then click OK.
  3. In the PivotTable Fields pane, drag Region into the Rows area.
  4. Drag Net Sales (NGN) into the Values area. It will appear as Sum of Net Sales (NGN).
  5. Right-click any value in the Sum of Net Sales (NGN) column and choose Sort, then Sort Largest to Smallest.
  6. Right-click any value again, choose Value Field Settings, click Number Format, and apply a currency-style Number format with a thousands separator and no decimal places.

Pivot Chart: Clustered Bar Chart (Pivot Chart)

  1. Click any cell inside the Pivot Table you just built.
  2. Go to PivotTable Analyze (or PivotChart Analyze) and click PivotChart.
  3. Choose Bar, then Clustered Bar, and click OK.
  4. Right-click the chart, choose Move Chart, and place it on the Pivot Charts sheet if you want it separated from the Pivot Table.
  5. Add a chart title: Total Net Sales by Region.

Practice Questions and Model Answers

Question 1Which region generated the highest Net Sales, and what was the amount?

AnswerSouth West generated the highest Net Sales, at N191,418,345.

Question 2Which region generated the lowest Net Sales, and what was the amount?

AnswerNorth East generated the lowest Net Sales, at N42,360,805.

Question 3Approximately how many times larger is South West's Net Sales than North East's? What might explain this gap?

AnswerSouth West's Net Sales are about 4.5 times North East's. This is expected because South West contains Lagos, the commercial hub with the highest branch count and order volume in the dataset (309 orders versus 86 in North East).

Pivot Table 2

Net Sales by Product Category and Region (Matrix Pivot Table)

Breaks Net Sales down by both Product Category and Region at the same time, letting learners practice a two-dimensional Pivot Table and spot which product lines perform best in which parts of the country.

Field Layout

RowsProduct Category
ColumnsRegion
Filter(none)
ValuesSum of Net Sales (NGN)

Step-by-Step Instructions

  1. Click any cell inside the Sales Data table and insert a new Pivot Table on a new worksheet.
  2. Drag Product Category into the Rows area.
  3. Drag Region into the Columns area.
  4. Drag Net Sales (NGN) into the Values area (Sum of Net Sales (NGN)).
  5. Right-click inside the Pivot Table, choose PivotTable Options, and on the Layout & Format tab, set 'For empty cells show' to 0 so blank combinations display as zero rather than blank.
  6. Apply a currency number format to the Values area as in Pivot Table 1.

Pivot Chart: Stacked Column Chart (Pivot Chart)

  1. With the Pivot Table selected, go to PivotTable Analyze and click PivotChart.
  2. Choose Column, then Stacked Column, and click OK.
  3. This shows, for each Product Category, how much of its sales came from each region stacked on top of each other.
  4. Add a chart title: Net Sales by Product Category, Split by Region.

Pivot Table 3

Sales Rep Performance (Orders, Average Order Value, Total Sales)

Introduces multiple Value fields in a single Pivot Table (Count, Average, Sum of the same or different fields), plus Top N filtering, to evaluate individual sales rep performance.

Field Layout

RowsSales Rep
Columns(none)
Filter(none)
ValuesCount of Order ID, Average of Net Sales (NGN), Sum of Net Sales (NGN)

Step-by-Step Instructions

  1. Build a new Pivot Table with Sales Rep in the Rows area.
  2. Drag Order ID into the Values area. Since Order ID is text, Excel automatically summarizes it as Count of Order ID.
  3. Drag Net Sales (NGN) into the Values area a second time. Click it, choose Value Field Settings, change the summary type to Average, and rename it to Avg Order Value.
  4. Drag Net Sales (NGN) into the Values area a third time. Leave it as Sum of Net Sales (NGN), and rename it to Total Net Sales.
  5. Right-click any value in the Total Net Sales column, choose Sort, then Sort Largest to Smallest.
  6. Right-click a Sales Rep name in the Rows area, choose Filter, then Top 10, and change the setting to Top 5 Items By Total Net Sales.

Pivot Chart: Combo Chart (Clustered Column for Orders + Line for Avg Order Value)

  1. With the Top 5 Pivot Table selected, insert a PivotChart and choose the Combo chart type.
  2. Set Count of Order ID and Total Net Sales as Clustered Columns, and Avg Order Value as a Line plotted on a Secondary Axis.
  3. Add a chart title: Top 5 Sales Reps: Orders, Total Sales, and Average Order Value.

Practice Questions and Model Answers

Question 1Who is the top sales rep by total Net Sales, and how many orders did that rep close?

AnswerAhmed Bello is the top sales rep, with total Net Sales of N62,705,725 from 73 orders.

Question 2What was Ahmed Bello's average order value?

AnswerAhmed Bello's average order value was N858,983.

Question 3Zainab Aliyu closed more orders than Ahmed Bello (95 versus 73) but generated less total revenue (N59,561,050 versus N62,705,725). What does this tell you about order count versus average order value?

AnswerA higher order count does not automatically mean higher revenue. Ahmed Bello's average order value (N858,983) is significantly higher than Zainab Aliyu's (N626,958), so fewer, higher-value orders produced more total revenue. This shows why Average Order Value is an important metric alongside order count.

Pivot Table 4

Quarterly Sales Trend (2023 to 2025)

Teaches date grouping in Pivot Tables (Year and Quarter) and builds a Line Pivot Chart to visualize trends over time, a core skill for spotting seasonality and growth.

Field Layout

RowsYear, then Quarter
Columns(none)
Filter(none)
ValuesSum of Net Sales (NGN)

Step-by-Step Instructions

  1. Build a new Pivot Table and drag Year into the Rows area, then drag Quarter into the Rows area directly beneath it (so Quarter is nested inside Year).
  2. Drag Net Sales (NGN) into the Values area.
  3. If you prefer to group directly from Order Date instead of using the pre-built Year and Quarter columns, drag Order Date into Rows, right-click any date, choose Group, and select both Quarters and Years.
  4. Apply a currency number format to the Values area.

Pivot Chart: Line Chart (Pivot Chart)

  1. With the Pivot Table selected, insert a PivotChart and choose Line, then Line with Markers.
  2. Add a chart title: Quarterly Net Sales Trend (2023 to 2025).
  3. Optional: right-click the Year field button on the chart and use the + or minus buttons to collapse or expand years for a cleaner view.

Pivot Table 5

Profit Margin Analysis by Product Category

Introduces Calculated Fields so learners can compute a ratio (Profit Margin %) directly inside the Pivot Table rather than in a helper column, and highlights that the highest-revenue category is not always the most profitable.

Field Layout

RowsProduct Category
Columns(none)
Filter(none)
ValuesSum of Net Sales (NGN), Sum of Profit (NGN), Profit Margin % (calculated field)

Step-by-Step Instructions

  1. Build a new Pivot Table with Product Category in Rows, and add Net Sales (NGN) and Profit (NGN) to the Values area (both as Sum).
  2. Click any cell inside the Pivot Table, go to PivotTable Analyze, click Fields, Items & Sets, then Calculated Field.
  3. Name the new field Profit Margin %, and in the Formula box enter: = 'Profit (NGN)' / 'Net Sales (NGN)'
  4. Click Add, then OK. The new Profit Margin % field appears as a fourth Value.
  5. Right-click any value in the Profit Margin % column, choose Value Field Settings, click Number Format, and apply Percentage with two decimal places.
  6. Sort the table by Profit Margin % largest to smallest to rank categories by profitability rather than by revenue.

Pivot Chart: Clustered Column Chart with Profit Margin % as a Line on a Secondary Axis (Combo Chart)

  1. Insert a PivotChart, choose Combo.
  2. Plot Sum of Net Sales (NGN) as a Clustered Column, and Profit Margin % as a Line on a Secondary Axis so the percentage is readable next to the much larger Naira values.
  3. Add a chart title: Net Sales versus Profit Margin % by Product Category.

Practice Questions and Model Answers

Question 1Which Product Category has the highest Profit Margin %, and what is the value?

AnswerFashion & Accessories has the highest Profit Margin %, at 33.19%.

Question 2Computing generates the highest total Net Sales (N205,496,335) of any category, yet has the lowest Profit Margin %. What is Computing's margin, and what does this suggest to management?

AnswerComputing's Profit Margin % is 13.83%, the lowest of all six categories. This suggests that although Computing drives the most revenue, it is the least profitable per Naira of sales, likely due to lower markups on laptops and accessories. Management may want to review pricing or supplier costs for this category.

Question 3Electronics recorded Net Sales of N117,780,120 and Profit of N21,557,120. Calculate the Profit Margin % and confirm it matches the Pivot Table.

AnswerN21,557,120 divided by N117,780,120 equals approximately 18.30%, which matches the Pivot Table's Profit Margin % for Electronics.

Pivot Table 6

Payment Method Distribution

Shows how to display Pivot Table values as a percentage of a total rather than raw counts, using Show Values As, and pairs it with a Pie Pivot Chart.

Field Layout

RowsPayment Method
Columns(none)
Filter(none)
ValuesCount of Order ID (shown twice: as Count and as % of Column Total)

Step-by-Step Instructions

  1. Build a new Pivot Table with Payment Method in Rows.
  2. Drag Order ID into the Values area twice. Excel will label them Count of Order ID and Count of Order ID2.
  3. Click the second one, open Value Field Settings, go to the Show Values As tab, and choose % of Column Total. Rename it to % of Orders.
  4. Sort the table by Count of Order ID largest to smallest.

Pivot Chart: Pie Chart (Pivot Chart)

  1. Select the Pivot Table, insert a PivotChart, and choose Pie.
  2. Use only the Count of Order ID field for the pie slices (a pie chart cannot meaningfully show two value fields at once).
  3. Add Data Labels showing Percentage, and add a chart title: Orders by Payment Method.

Practice Questions and Model Answers

Question 1Which payment method(s) were used most often, and what percentage of total orders do they represent?

AnswerPOS and Bank Transfer are tied for the most-used payment methods, each accounting for 323 orders, or 29.4% of total orders.

Question 2Which payment method was used least often, and what percentage of orders does it represent?

AnswerUSSD was used least often, accounting for 76 orders, or 6.9% of total orders.

Question 3What percentage of all orders were paid for using either POS or Bank Transfer combined?

AnswerPOS and Bank Transfer together account for 58.8% of all orders (29.4% plus 29.4%).

Pivot Table 8

Teaches Value Filters (Top 10) so learners can quickly isolate the best-performing products out of dozens in the dataset, a very common real-world request.

Field Layout

RowsProduct Name
Columns(none)
Filter(none)
ValuesSum of Net Sales (NGN)

Step-by-Step Instructions

Pivot Chart: Bar Chart (Pivot Chart)

Pivot Table 10

Region by Payment Method Cross-Tab

A second two-dimensional Pivot Table exercise, this time using counts instead of sums, and paired with a 100% Stacked Column Pivot Chart to compare proportions rather than raw totals across regions.

Field Layout

RowsRegion
ColumnsPayment Method
Filter(none)
ValuesCount of Order ID

Step-by-Step Instructions

  1. Build a new Pivot Table with Region in Rows and Payment Method in Columns.
  2. Drag Order ID into the Values area (Count of Order ID).
  3. Right-click inside the table, choose PivotTable Options, and set 'For empty cells show' to 0.

Pivot Chart: 100% Stacked Column Chart (Pivot Chart)

  1. Insert a PivotChart from this Pivot Table and choose Column, then 100% Stacked Column.
  2. This normalizes every region's bar to the same height so you can compare the mix of payment methods fairly, even though regions have different total order counts.
  3. Add a chart title: Payment Method Mix by Region.

Practice Questions and Model Answers

Question 1Which region has the highest count of POS orders, and how many?

AnswerSouth West has the highest count of POS orders, with 94.

Question 2Which region relies most heavily on USSD as a proportion of its own orders? (Hint: divide each region's USSD count by that region's total orders.)

AnswerNorth East relies most heavily on USSD proportionally: 11 of its 86 total orders (about 12.8%) are USSD, a higher share than any other region, even though its raw USSD count is not the largest.

Question 3Add up all the payment method counts for South West in this Pivot Table (POS 94, Bank Transfer 90, Card 53, Cash 49, USSD 23). Does the total match South West's order count of 309 from Pivot Table 1?

AnswerYes: 94 + 90 + 53 + 49 + 23 = 309, which matches South West's total order count from Pivot Table 1. This is a useful way to double-check that a cross-tab Pivot Table accounts for every record.

Summary and Further Practice

Further practice ideas using the same dataset:
