This is Part 2 of 2 of the training guide, and it is the answer key to Part 1 - Problems & Tasks. It walks through the exact Power Query step for every problem column, the full DAX formula for every measure, the complete relationship setup for the data model, and a build-by-build guide for every chart on every dashboard. Dim_Departments Dimension table

Master list of the 10 departments used across every fact sheet in this workbook. This is the sheet every department fact table connects back to in Power BI.

ColumnPower Query solution (exact steps)
DepartmentID
Text (short code)
Right-click DepartmentID ▸ Transform ▸ Trim, then Transform ▸ Clean, then Transform ▸ Capitalize Each Word (or UPPERCASE, matching your naming standard). In the formula bar this is Text.Proper(Text.Clean(Text.Trim([DepartmentID]))). Do this before any grouping or relationship so 'Lagos', 'lagos ' and 'LAGOS' collapse into one value.
DepartmentName
Text
Right-click DepartmentName ▸ Transform ▸ Trim, then Transform ▸ Clean, then Transform ▸ Capitalize Each Word (or UPPERCASE, matching your naming standard). In the formula bar this is Text.Proper(Text.Clean(Text.Trim([DepartmentName]))). Do this before any grouping or relationship so 'Lagos', 'lagos ' and 'LAGOS' collapse into one value.

Text		Set correct data type on import; no other cleaning required.
HeadOfficeLocation
Text
Right-click HeadOfficeLocation ▸ Transform ▸ Trim, then Transform ▸ Clean, then Transform ▸ Capitalize Each Word (or UPPERCASE, matching your naming standard). In the formula bar this is Text.Proper(Text.Clean(Text.Trim([HeadOfficeLocation]))). Do this before any grouping or relationship so 'Lagos', 'lagos ' and 'LAGOS' collapse into one value.
DateEstablishedInERP
Date
Select DateEstablishedInERP ▸ Transform ▸ Data Type ▸ Date. Power Query will fail on the text-formatted rows. Fix it before converting: Add Column ▸ Custom Column with if Text.Contains([DateEstablishedInERP], ",") then Date.FromText([DateEstablishedInERP], "en-US") else if Text.Contains([DateEstablishedInERP], "/") then Date.FromText([DateEstablishedInERP], "en-GB") else Date.FromText([DateEstablishedInERP]) then replace the original column with this one and set its type to Date. Locale matters: en-GB reads 23/07/2026 as day/month/year.

Handling the two relationships marked "inactive": Dim_Employees is the one table that more than one fact table wants to relate to more than once (for example Operations has SupervisorEmployeeID, but Dim_Employees is already the 'one' side of the Human_Resources relationship on EmployeeID). Power BI allows only one ACTIVE relationship between two tables at a time. The extra relationships to Dim_Employees from Operations and Internal_Control must be created as INACTIVE relationships and invoked inside a measure with USERELATIONSHIP() whenever a report needs 'production supervised by' or 'audit finding owned by' rather than the default employee link.

In practice: create the relationship, right-click it in Model view ▸ it will appear as a dashed line if Power BI auto-marks it inactive (or set it inactive yourself if there is already an active path). Then in any measure that needs it, wrap the calculation: Volume By Supervisor = CALCULATE([Total Volume Produced (HL)], " "USERELATIONSHIP(Operations[SupervisorEmployeeID], Dim_Employees[EmployeeID])).

DAX Measures - Solutions

Create every measure below in its stated table (New Measure), not as a calculated column, so it recalculates correctly with every filter/slicer on the report page.

Operations

MeasurePurposeDAX solution
Total Volume Produced (HL)Sum of all batch volumes actually produced.Total Volume Produced (HL) = SUM(Operations[BatchVolume_HL])
Total Target Volume (HL)Sum of all planned/target volumes.Total Target Volume (HL) = SUM(Operations[TargetVolume_HL])
Production Efficiency %Actual volume produced as a percentage of target volume.Production Efficiency % = DIVIDE([Total Volume Produced (HL)], [Total Target Volume (HL)], 0)
Total Downtime HoursSum of downtime hours across all batches.Total Downtime Hours = SUM(Operations[DowntimeHours])
Quality Pass Rate %Share of batches with a QualityStatus of Pass.Quality Pass Rate % = DIVIDE(CALCULATE(COUNTROWS(Operations), Operations[QualityStatus] = "Pass"), COUNTROWS(Operations), 0)

Supply_Chain

MeasurePurposeDAX solution
Total Procurement Spend (NGN)Sum of quantity ordered multiplied by unit cost.Total Procurement Spend (NGN) = SUMX(Supply_Chain, Supply_Chain[QuantityOrdered] * Supply_Chain[UnitCost_NGN])
On-Time Delivery %Share of purchase orders delivered On Time.On-Time Delivery % = DIVIDE(CALCULATE(COUNTROWS(Supply_Chain), Supply_Chain[DeliveryStatus] = "On Time"), COUNTROWS(Supply_Chain), 0)
Average Lead Time (Days)Average number of days between order date and delivery date.Average Lead Time (Days) = AVERAGEX(Supply_Chain, DATEDIFF(Supply_Chain[OrderDate], Supply_Chain[DeliveryDate], DAY))
Total Open POsCount of purchase orders not yet delivered.Total Open POs = CALCULATE(COUNTROWS(Supply_Chain), Supply_Chain[DeliveryStatus] IN {"Pending", "Delayed"})

Legal

MeasurePurposeDAX solution
Total Active Contract Value (NGN)Sum of contract value for contracts that are not expired.Total Active Contract Value (NGN) = CALCULATE(SUM(Legal[ContractValue_NGN]), Legal[ContractExpiryDate] >= TODAY())
Contracts Expiring Next 90 DaysCount of contracts expiring in the next 90 days, for renewal planning.Contracts Expiring Next 90 Days = CALCULATE(COUNTROWS(Legal), Legal[ContractExpiryDate] >= TODAY(), Legal[ContractExpiryDate] <= TODAY() + 90)
Breach Case CountCount of cases flagged as Breach Identified.Breach Case Count = CALCULATE(COUNTROWS(Legal), Legal[ComplianceStatus] = "Breach Identified")
