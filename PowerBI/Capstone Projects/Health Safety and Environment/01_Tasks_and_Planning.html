1. Program Overview & Learning Objectives

This document is the first of two companion HTML files built around the HSE_Training_Dataset.xlsx workbook and its accompanying Word document. It is designed as a hands-on workbook: it tells you what needs to be done at every stage of a real Power BI project - understanding the data, cleaning it, modeling it, writing the DAX, and building the report - without giving away the finished answer. The second file, 02_Full_Solution_Walkthrough.html, contains the complete worked solution with every DAX formula, every modeling decision explained, and every dashboard build step documented in full.

7 tables78 columns~12,900 total data rows 30+ DAX measures5 dashboard pages

By the end of this training, a student will be able to:

  • Explain the purpose and data type of every column in a realistic multi-table HSE dataset.
  • Import and clean a multi-sheet Excel data source in Power Query.
  • Design a star-schema data model and correctly assign cardinality and filter direction to every relationship.
  • Explain why a table pair can only have one active relationship, and use USERELATIONSHIP to work around it.
  • Write DAX measures spanning basic aggregation, CALCULATE-based filtering, time intelligence, and SWITCH-based status logic.
  • Design and build a 5-page, KPI-driven Power BI report using industry-standard HSE metrics (LTIFR, TRIR, Severity Rate).

4. Tasks - Data Loading & Power Query Cleaning

Goal of this section: before anything is modeled or charted, every one of the seven tables must be inspected and cleaned in Power Query. Work through the checklist below table by table. Do not skip a table just because it "looks" clean in the preview grid - always check data types explicitly.

Task Set 1 - Import

  • Task 1.1 - Connect to HSE_Training_Dataset.xlsx using Get Data > Excel Workbook.
  • Task 1.2 - In the Navigator, select only the seven data tables (dim_Date, dim_Site, dim_Employee, fact_Incidents, fact_Observations, fact_Environmental, fact_Training). Leave README, Data_Dictionary and Model_Map unchecked.
  • Task 1.3 - Click "Transform Data", not "Load", so you can inspect every table before it enters the model.

Task Set 2 - dim_Date

  • Task 2.1 - Verify the Date column type is Date, with no hidden time component.
  • Task 2.2 - Verify IsWeekend imported as True/False (Boolean), not text.
  • Task 2.3 - Verify DateKey is Whole Number.

Task Set 3 - dim_Site

  • Task 3.1 - Trim and Clean every text column to remove hidden whitespace.
  • Task 3.2 - Confirm EmployeeCount and YearOpened are Whole Number.

Task Set 4 - dim_Employee

  • Task 4.1 - Confirm DateOfBirth and HireDate are Date type.
  • Task 4.2 - Decide (and justify in your own notes) why Age should be built as a DAX measure rather than a static Power Query column. Do not build the Age column in Power Query - this is intentional.

Task Set 5 - fact_Incidents

  • Task 5.1 - Trim DateKey and SiteID.
  • Task 5.2 - Confirm EstimatedCostUSD is Decimal Number.
  • Task 5.3 - Confirm DateClosed is Date type and that empty values are true nulls, not the text "None".
  • Task 5.4 - Confirm DaysLost is Whole Number.

Task Set 6 - fact_Observations, fact_Environmental, fact_Training

  • Task 6.1 - Confirm Score is Whole Number in both fact_Observations and fact_Training.
  • Task 6.2 - Confirm Value and ComplianceLimit in fact_Environmental are Decimal Number.
  • Task 6.3 - Confirm ExpiryDateKey in fact_Training is Whole Number, and that blank expiries import as null rather than 0.
  • Task 6.4 - Trim all ID/key columns across all three tables.

Task Set 7 - Finish

  • Task 7.1 - Click Close & Apply once every table passes its checklist above.

6. Tasks - DAX Measures to Build

Instructions: for each measure below, write the DAX formula yourself in a blank measure, name it exactly as shown, and place it in a new table called _Measures. Do not look at the solution file until you have made a genuine attempt. Think about which DAX function family (basic aggregation, CALCULATE + filter, time intelligence, or SWITCH) each one probably needs before you start typing.

Group 1 - Core Counting Measures

  • Total Incidents - How many HSE incidents have been logged in the current filter context?
  • Total Near Misses - How many of those incidents were Near Misses specifically?
  • Total LTI - How many were Lost Time Injuries?
  • Total Fatalities - How many were Fatalities?
  • Total Days Lost - How many total workdays were lost across all incidents?
  • Total Incident Cost - What is the total estimated financial cost of all incidents?
  • Total Observations / Safe Observations / At-Risk Observations - How many safety observations were logged, and how many were safe vs at-risk?
  • Total Env Readings / Compliant Readings / Non-Compliant Readings - How many environmental readings were taken, and how many were compliant vs not?
  • Total Trainings / Passed Trainings / Failed Trainings - How many training sessions were delivered, and what were the pass/fail counts?

Group 2 - Time Intelligence Measures

  • Incidents PY - How many incidents happened in the same period last year?
  • Incidents YoY % Change - Are incidents trending up or down compared to last year, in percentage terms?
  • Incidents YTD - What is the running year-to-date total of incidents?
  • Incidents 3M Avg - What does the smoothed 3-month rolling average of incidents look like?

Group 3 - Rate and Ratio Measures

  • Active Employees - How many unique employees exist in the current filter context?
  • Total Hours Worked (estimated) - Approximately how many labor hours were worked in the current filter context?
  • LTIFR - What is the Lost Time Injury Frequency Rate, normalized per 200,000 hours worked?
  • Total Recordable Incidents / TRIR - What is the Total Recordable Incident Rate, per 200,000 hours worked?
  • Severity Rate - How severe (in days lost) are incidents once normalized for exposure hours?
  • Incidents per 100 Employees - What is a simpler, non-hours-based way to compare incident rates across sites of different sizes?
  • Average Cost per Incident - What is the average financial cost per incident?
  • Near Miss to LTI Ratio - How many near misses are reported for every one lost-time injury?

Group 4 - Safety Behaviour (BBS) Measures

  • Safe Behavior % - What percentage of all logged observations were safe behavior?
  • Average Safety Score - What is the average observation score (1-10)?
  • High Risk Observations - How many at-risk observations were rated High risk specifically?

Group 5 - Environmental Measures

  • Environmental Compliance % - What percentage of environmental readings were within their compliance limit?
  • Avg Environmental Value - What is the average reading value, broken out by parameter type?
  • Variance to Limit % - How far over or under the compliance limit is the average reading running?

Group 6 - Training Measures

  • Training Pass Rate % - What percentage of training assessments were passed?
  • Average Training Score - What is the average assessment score across all training records?
  • Certifications Expiring Soon - How many certifications are flagged as Expiring Soon?
  • Certifications Expiring Next 30 Days - How many certifications will expire in the next 30 calendar days from today - using the INACTIVE expiry-date relationship?

Group 7 - KPI Status Helper Measures

  • LTIFR Status - Translate the numeric LTIFR into a plain-language traffic-light status (On Target / Watch / Off Target).
  • Environmental Compliance Status - Translate the numeric compliance percentage into a plain-language status (Compliant / Marginal / Non-Compliant).

7. Tasks - Dashboard Pages to Build

Goal of this section: build five report pages. For each page, the title is fixed (use it exactly), but you must choose the visual type, fields, and layout yourself using the chart list as a brief - then compare your build against the fully-explained version in the solution file.
Dashboard Page 1 - "HSE Executive Overview"
A single-glance summary for senior management.
  • Slicers: Year, Site, Department
  • KPI cards: Total Incidents (with YoY % change), LTIFR, TRIR, Total Days Lost, Environmental Compliance %, Training Pass Rate
  • Chart: Monthly incident trend, current year vs prior year overlay
  • Chart: Incidents by Site - raw count vs rate per 100 employees
  • Chart: Incidents by Severity (proportion)
  • Chart: Geographic distribution of incidents by Region
Dashboard Page 2 - "Incident Deep Dive"
Root-cause and corrective-action analysis for HSE managers.
  • Slicers: Year, IncidentType, Severity
  • KPI cards: Total Recordable Incidents, Near Miss to LTI Ratio, Average Cost per Incident
  • Chart: Incident count by type (pyramid-style ranking)
  • Chart: Incident category mix by department (100% stacked)
  • Matrix: Root cause by site, with cost
  • Chart: Days lost vs cost scatter
  • Table: Open investigations and overdue corrective actions
Dashboard Page 3 - "Safety Behaviour & Leading Indicators (BBS)"
Show how proactive behaviour observations connect to lagging incident numbers.
  • Slicers: Year, Site, Category
  • KPI cards: Total Observations, Safe Behavior %, Average Safety Score
  • Chart: Observations by category, split safe vs at-risk
  • Chart: Safe vs at-risk trend over time
  • Chart: Risk rating split of at-risk observations
  • Table: Site ranking by Safe Behavior %, worst first
Dashboard Page 4 - "Environmental Compliance"
Monitor environmental performance against regulatory/internal limits.
  • Slicers: Year, ParameterType, Site
  • KPI cards: Environmental Compliance %, Non-Compliant Readings, Average CO2 Emissions
  • Chart: Average reading by site and parameter
  • Chart: Monthly trend vs compliance limit (with reference line)
  • Chart: Compliance status split
  • Table: Non-compliant readings investigation list
Dashboard Page 5 - "Training & Competence"
Track training delivery, pass rates, and certification currency.
  • Slicers: Year, TrainingCourse, Department
  • KPI cards: Total Trainings Delivered, Training Pass Rate, Certifications Expiring (Next 30 Days)
  • Chart: Training volume by course
  • Chart: Monthly pass rate trend
  • Chart: Certification status overview
  • Table: Employees needing refresher training
