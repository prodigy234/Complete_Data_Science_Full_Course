1. Program Overview & Learning Objectives

This document is the first of two companion HTML files built around the NTMB_Loan_Portfolio_Dataset.xlsx workbook and its accompanying Word document. It is designed as a hands-on workbook: it tells you what needs to be done at every stage of a real Power BI project without giving away the finished answer. The second file, 02_Full_Solution_Walkthrough.html, contains the complete worked solution.

9 tables75+ columns~39,000 total data rows 25+ DAX measures5 dashboard pages

By the end of this training, a student will be able to:

  • Explain the purpose and data type of every column in a realistic multi-table loan portfolio dataset.
  • Import and clean a multi-sheet Excel data source in Power Query.
  • Design a star-schema data model with a bridge fact table, and correctly assign cardinality and filter direction to every relationship.
  • Explain why a table pair can only have one active relationship, and use USERELATIONSHIP to work around it - in two different fact tables that each have two dates.
  • Write DAX measures spanning basic aggregation, CALCULATE-based filtering, time intelligence, SWITCH-based status logic, and USERELATIONSHIP.
  • Design and build a 5-page Power BI report using industry-standard banking KPIs (NPL Ratio, PAR30/60/90, Collection Efficiency Ratio).

4. Tasks - Data Loading & Power Query Cleaning

Goal of this section: before anything is modeled or charted, every one of the nine tables must be inspected and cleaned in Power Query. Work through the checklist below table by table.

Task Set 1 - Import

  • Task 1.1 - Connect to NTMB_Loan_Portfolio_Dataset.xlsx using Get Data > Excel Workbook.
  • Task 1.2 - In the Navigator, select only the nine data tables (dim_Date, dim_Branch, dim_Customer, dim_LoanOfficer, dim_LoanProduct, fact_Applications, fact_Portfolio, fact_Repayments, fact_Collections). Leave README, Data_Dictionary and Model_Map unchecked.
  • Task 1.3 - Click "Transform Data", not "Load", so you can inspect every table before it enters the model.

Task Set 2 - dim_Date

  • Task 2.1 - Verify the Date column type is Date, with no hidden time component.
  • Task 2.2 - Verify IsWeekend imported as True/False (Boolean), not text.
  • Task 2.3 - Verify DateKey is Whole Number.

Task Set 3 - dim_Branch, dim_LoanOfficer, dim_LoanProduct

  • Task 3.1 - Trim and Clean every text column in dim_Branch.
  • Task 3.2 - Confirm StaffCount and YearOpened are Whole Number.
  • Task 3.3 - Confirm HireDate in dim_LoanOfficer is Date type.
  • Task 3.4 - Confirm MinAmount, MaxAmount, and BaseInterestRatePct in dim_LoanProduct are Decimal Number.

Task Set 4 - dim_Customer

  • Task 4.1 - Confirm DateOfBirth and OnboardingDate are Date type.
  • Task 4.2 - Decide (and justify in your own notes) why Age and Customer Tenure should be built as DAX measures rather than static Power Query columns.

Task Set 5 - fact_Applications and fact_Portfolio (the two-date tables)

  • Task 5.1 - Confirm DateKey and DecisionDateKey in fact_Applications are both Whole Number, with true nulls for Pending/Withdrawn applications.
  • Task 5.2 - Confirm DisbursementDateKey and MaturityDateKey in fact_Portfolio are both Whole Number.
  • Task 5.3 - Confirm AmountRequested, PrincipalAmount, InterestRatePct, OutstandingBalance, and MonthlyInstallment are Decimal Number.
  • Task 5.4 - Confirm TenorMonths, DaysPastDue, CreditScoreAtApplication, and ProcessingDays are Whole Number.
  • Task 5.5 - Trim every ID/key column in both tables.

Task Set 6 - fact_Repayments and fact_Collections

  • Task 6.1 - Confirm ScheduledAmount, ActualAmountPaid, and AmountRecovered are Decimal Number.
  • Task 6.2 - Confirm DaysLate is Whole Number.
  • Task 6.3 - Trim LoanID and OfficerID in both tables.

Task Set 7 - Finish

  • Task 7.1 - Click Close & Apply once every table passes its checklist above.

6. Tasks - DAX Measures to Build

Instructions: for each measure below, write the DAX formula yourself in a blank measure, name it exactly as shown, and place it in a new table called _Measures.

Group 1 - Core Counting Measures

  • Total Applications - How many loan applications have been submitted in the current filter context?
  • Approved Applications / Rejected Applications / Pending Applications - How many applications fall into each outcome status?
  • Total Loans Disbursed / Total Principal Disbursed - How many loans have been paid out, and what is the total amount lent?
  • Total Outstanding Balance - How much do customers currently owe across the entire loan book?
  • Non-Performing Loan Count / Non-Performing Loan Balance - How many loans - and how much balance - are classified as non-performing?
  • Total Scheduled Repayments / Total Actual Repayments - How much was supposed to be repaid, and how much was actually repaid?
  • Total Amount Recovered - How much money has been recovered specifically through collections effort?

Group 2 - Time Intelligence Measures

  • Principal Disbursed PY - How much was disbursed in the same period last year?
  • Disbursement YoY % Change - Is the lending book growing or shrinking compared to last year?
  • Disbursements YTD - What is the running year-to-date total of disbursements?
  • NPL Ratio 3M Avg - What does the smoothed 3-month rolling average of the NPL ratio look like?

Group 3 - Rate and Ratio Measures

  • Approval Rate % / Rejection Rate % - What percentage of applications are approved vs rejected?
  • Average Processing Days - On average, how many days does it take to reach a lending decision?
  • NPL Ratio % - What percentage of the outstanding book is classified as non-performing?
  • PAR 30 / PAR 60 / PAR 90 - What percentage of the outstanding book is 30, 60, and 90+ days past due?
  • Collection Efficiency Ratio - What percentage of scheduled repayments were actually collected?
  • Average Interest Rate - What is the average interest rate across the portfolio?
  • Write-Off Rate % - What percentage of everything ever disbursed has been permanently written off?

Group 4 - Application Funnel & Channel Measures

  • Application Channel Share % - What proportion of applications come through each channel?
  • Average Credit Score - What is the average credit score of applicants, and how does it trend?

Group 5 - Collections & Recovery Measures

  • Total Collection Actions / Successful Collection Actions - How many collection actions were taken, and how many resulted in payment?
  • Collection Success Rate % - What percentage of collection actions succeed?
  • Recovery Rate % - What fraction of the non-performing balance has been recovered?

Group 6 - KPI Status Helper Measures

  • NPL Ratio Status - Translate the numeric NPL ratio into a traffic-light status (Healthy / Watch / Elevated Risk).
  • Approval Rate Status - Translate the numeric approval rate into a status (Strong / Moderate / Weak).

Group 7 - The Inactive-Relationship Measures (USERELATIONSHIP)

  • Loans Maturing Next 30 Days - How many active loans mature in the next 30 days - using the INACTIVE MaturityDateKey relationship?
  • Applications Beyond Decision SLA - How many pending applications have taken more than 14 days - using the INACTIVE DecisionDateKey relationship?

7. Tasks - Dashboard Pages to Build

Goal of this section: build five report pages using the chart list as a brief.
Dashboard Page 1 - "Executive Portfolio Overview"
A single-glance summary for senior management and the board.
  • Slicers: Year, Region, ProductCategory
  • KPI cards: Total Principal Disbursed (with YoY % change), Total Outstanding Balance, NPL Ratio %, Approval Rate %, Collection Efficiency Ratio, Disbursements YTD
  • Chart: Monthly disbursement trend, current year vs prior year overlay
  • Chart: Disbursement volume vs NPL ratio by branch
  • Chart: Portfolio balance by risk classification
  • Chart: Geographic distribution of the loan book by region
Dashboard Page 2 - "Loan Origination & Application Funnel"
Analyze the application-to-disbursement funnel for the credit/origination team.
  • Slicers: Year, ApplicationChannel, ProductCategory
  • KPI cards: Total Applications, Approval Rate %, Average Processing Days
  • Chart: Application-to-disbursement funnel
  • Chart: Top rejection reasons
  • Chart: Application outcome mix by channel
  • Chart: Processing time trend
  • Table: Applications beyond SLA - action required
Dashboard Page 3 - "Portfolio Risk & NPL Analysis"
Deep-dive into loan book quality for the risk management team and credit committee.
  • Slicers: Year, RiskClassification, ProductCategory
  • KPI cards: NPL Ratio %, Write-Off Rate %, Average Interest Rate
  • Chart: Portfolio at risk trend (PAR30 / PAR60 / PAR90)
  • Chart: NPL ratio by product
  • Matrix: NPL balance by credit score band and region
  • Chart: Non-performing balance by collateral type
  • Table: Loans maturing in the next 30 days - relationship manager watch list
Dashboard Page 4 - "Collections & Recovery Performance"
Track the effectiveness of the collections/recovery team on delinquent accounts.
  • Slicers: Year, ActionType, Officer
  • KPI cards: Total Collection Actions, Collection Success Rate %, Total Amount Recovered
  • Chart: Collection actions by type and outcome
  • Chart: Monthly recovery trend
  • Chart: Collection action outcome split
  • Table: Officer performance ranking - recovery effectiveness
Dashboard Page 5 - "Customer & Product Analytics"
Understand the customer base and product mix for strategy and cross-sell planning.
  • Slicers: Year, CustomerSegment, CreditScoreBand
  • KPI cards: Total Loans Disbursed, Total Principal Disbursed, Average Interest Rate
  • Chart: Product mix - volume vs value
  • Chart: Disbursement share by customer segment
  • Chart: Approval rate vs NPL ratio by credit score band
  • Table: Portfolio profile by income band
