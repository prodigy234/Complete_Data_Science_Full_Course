Human Resources

The employee master. Every other department sheet references this table through Employee ID, so the quality of this sheet's cleaning directly determines whether every relationship in the data model works correctly.

1. Columns, Problems, and Cleaning Tasks (Power Query)

ColumnTypeWhat It MeansProblem In The DataYour Task
Employee ID id The unique identifier for every staff member, format EMP-0001. This is the single most important column in the entire workbook, every other sheet joins back to it. A small number of employees appear twice, entered on two different dates with a slightly different name spelling each time. Identify and remove the duplicate employee rows, keeping the more complete and more recent entry.
Full Name text The employee's full name. Inconsistent casing throughout: some names in lowercase, some in full capitals, some with leading or trailing spaces. Standardize every name to proper case and trim all leading and trailing whitespace.
Department Code id Links this employee to their department on the Company Structure sheet. A handful of rows carry a department code that does not exist on the Company Structure sheet, either mistyped or left over from a department that was renamed. Identify every Department Code that has no match on Company Structure and correct or flag it.
Job Title text The employee's current job title. Minor inconsistency in abbreviation, for example "Mgr" versus "Manager". Standardize job title abbreviations to full words.
Date of Hire date The date the employee joined the company. Three different date formats appear in the same column: DD/MM/YYYY, YYYY-MM-DD, and a written format like "12 May 2021". Convert every value in this column to a single, consistent date type.
Employment Status text Whether the employee is Active, Resigned, or Terminated. Inconsistent casing and stray spaces: "active", "ACTIVE", "Active ". Standardize to a single consistent capitalization with no trailing spaces.
Gender text The employee's gender. Recorded inconsistently as "M"/"F" in some rows and "Male"/"Female" in others. Standardize to one consistent format across the whole column.
Monthly Salary (NGN) currency The employee's gross monthly salary in Naira. Stored as a mix of plain numbers, numbers with commas, and text values with a currency symbol, for example 150000, "150,000", and "N150,000". Remove all text and currency symbols and convert the entire column to a clean numeric type.
Leave Days Remaining number The employee's remaining annual leave balance in days. A number of rows are blank, and one row shows a negative value, which is not logically possible for a remaining balance. Decide a rule for blank values, and flag or investigate the negative value rather than silently deleting it.
Phone Number text The employee's contact phone number. Recorded in at least three different formats: "08012345678", "+2348012345678", and "0801-234-5678". Standardize every phone number to one consistent format.

1. Columns, Problems, and Cleaning Tasks (Power Query)

ColumnTypeWhat It MeansProblem In The DataYour Task
Request ID id The unique identifier for every admin request, format ADM-0001. Clean, no duplicates found in this column. Confirm the ID column has no duplicates before building any visual on it.

Cost (NGN) currency The cost associated with fulfilling the request. Mixed currency formatting, some with the Naira symbol, some plain numbers, one or two with stray spaces. Clean the column to a single consistent numeric currency format.
Status text Pending, Approved, Rejected, or Completed. Inconsistent casing and a couple of trailing spaces. Standardize status values to one consistent set.
