Human Resources

The employee master. Every other department sheet references this table through Employee ID, so the quality of this sheet's cleaning directly determines whether every relationship in the data model works correctly.

1. Column By Column Cleaning Solutions (Power Query)

ColumnProblemDetailed Solution
Employee ID A small number of employees appear twice, entered on two different dates with a slightly different name spelling each time.
Solution: In Power Query, select the "Employee ID" column. Go to Home, then Remove Rows, then Remove Duplicates. Before removing anything, sort the table so the more complete or more recent row for each duplicate sits first, since Remove Duplicates always keeps the first occurrence and discards the rest. If you need to choose which duplicate to keep based on a rule rather than row order, use Home, Group By instead, grouping on "Employee ID" and aggregating to select the preferred row.
Full Name Inconsistent casing throughout: some names in lowercase, some in full capitals, some with leading or trailing spaces.
Solution: Select the "Full Name" column. Apply Transform, Format, Trim to remove leading and trailing spaces, then Transform, Format, Capitalize Each Word (or Lowercase / Uppercase, whichever the business has agreed as the standard) to make every value consistent.
Department Code A handful of rows carry a department code that does not exist on the Company Structure sheet, either mistyped or left over from a department that was renamed.
Solution: In Power Query, select the "Human Resources" query, then Home, Merge Queries. Merge it with the Company Structure query, matching "Department Code" to Department Code, and set the Join Kind to Left Anti. This isolates every row whose department code does not exist on Company Structure. Correct each one against the real Company Structure list, or flag it for the department to confirm.
Job Title Minor inconsistency in abbreviation, for example "Mgr" versus "Manager".
Solution: Select the "Job Title" column and use Transform, Replace Values to expand each abbreviation to its full form, one Replace Values step per abbreviation. Chain the steps so every known abbreviation is covered, then spot check the column quality bar for anything still inconsistent.
Date of Hire Three different date formats appear in the same column: DD/MM/YYYY, YYYY-MM-DD, and a written format like "12 May 2021".
Solution: Select the "Date of Hire" column. Go to Transform, Data Type, and choose Date. Power Query will convert every value it can parse automatically and mark the rest as errors. For the rows that error, usually the written format like "12 May 2021", use Add Column, Custom Column with Date.FromText([Date of Hire]) to force a parse, or first split out the written values with a filter, standardize them, and merge them back in before setting the final Date type on the whole column.
Employment Status Inconsistent casing and stray spaces: "active", "ACTIVE", "Active ".
Solution: Select the "Employment Status" column. Apply Transform, Format, Trim to remove leading and trailing spaces, then Transform, Format, Capitalize Each Word (or Lowercase / Uppercase, whichever the business has agreed as the standard) to make every value consistent.
Gender Recorded inconsistently as "M"/"F" in some rows and "Male"/"Female" in others.
Solution: Select the "Gender" column and review the Power Query column quality and column distribution bars (View tab) to see exactly which rows are inconsistent, then apply the appropriate Transform step, Replace Values, Data Type change, or Trim and Clean, until the column reads 100% valid.
Monthly Salary (NGN) Stored as a mix of plain numbers, numbers with commas, and text values with a currency symbol, for example 150000, "150,000", and "N150,000".
Solution: Select the "Monthly Salary (NGN)" column. Use Transform, Replace Values twice, once to remove the currency symbol and once to remove thousands-separator commas. Then go to Transform, Data Type, and choose Decimal Number. Confirm the column quality bar reads 100% valid afterward, any remaining errors mean a value still has stray text in it that needs a further Replace Values pass.
Leave Days Remaining A number of rows are blank, and one row shows a negative value, which is not logically possible for a remaining balance.
Solution: Select the "Leave Days Remaining" column. Right click the column header, choose Replace Values, and apply your agreed rule: replace blank with a specific default value if one is defensible, or leave the row identifiable for a filter based exception report if the true value cannot be assumed. Do not silently delete rows with blanks in this column without checking whether the blank itself is meaningful.
Phone Number Recorded in at least three different formats: "08012345678", "+2348012345678", and "0801-234-5678".
Solution: Select the "Phone Number" column and review the Power Query column quality and column distribution bars (View tab) to see exactly which rows are inconsistent, then apply the appropriate Transform step, Replace Values, Data Type change, or Trim and Clean, until the column reads 100% valid.
