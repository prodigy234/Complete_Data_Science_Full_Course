1. Recommended Cleaning Order

Follow this sequence in Power Query Editor so that later steps rely on already-clean upstream data.

Step 1. Clean the two simple dimension tables first: Plants and Distributors. Add the missing HQ-LAGOS row to Plants.

Step 2. Clean Employees (HR) next, since eight other sheets depend on EmployeeID matching correctly.

Step 3. Clean each department fact table one at a time: Operations, Supply Chain, Legal, Admin, Customer Service, I.T, Accounts and Finance, Risk Management and Compliance, Internal Control.

Step 4. Load everything to the Power BI data model, build every relationship, add the Calendar table, then write the DAX measures.

Step 5. Build the dashboard pages, starting with the Executive Overview page last, since it reuses measures from every other page.

ColumnProblem recapFull Power Query solution
EmployeeIDA small number of EmployeeID values appear twice because the entire row was duplicated during data entry.Use Home > Remove Rows > Remove Duplicates on the whole table after trimming text columns, so that whitespace differences do not hide true duplicates.
FullNameInconsistent casing (some names in FULL UPPER CASE, some in lower case) and extra leading and trailing spaces on some rows.Apply Transform > Format > Trim, then Transform > Format > Capitalize Each Word.
DepartmentMixed casing (UPPER CASE variants) and an inconsistent way of writing I.T (sometimes 'I.T', sometimes 'IT ' with a trailing space), which stops department names from grouping correctly.Trim the column, then use Replace Values to force every I.T variant to the single value 'I.T', and apply Capitalize Each Word or a manual conditional column for exceptions like I.T.

HireDateThree different date formats are mixed in the same column: day/month/year text, month-day-year text (genuinely ambiguous for two digit day and month values), and native date values, which prevents Power Query from auto detecting one single date type.Use Transform > Data Type > Date with Locale set explicitly to English (United Kingdom) for the day/month/year values; isolate and separately fix the month-day-year values using Add Column > Date > Parse with a custom locale, then append the two cleaned columns back together.
GenderA handful of rows use single letter codes (M or F) instead of the full word used everywhere else.Use Replace Values: M to Male, F to Female.
StateOfOriginMixed casing, an inconsistent 'State' suffix on some values (for example ' Lagos State' with a leading space), and some blank cells for a handful of employees.Trim, remove the word ' State' using Replace Values or Extract Text Before Delimiter, apply Capitalize Each Word, then use Replace Errors or Fill Down / a placeholder value such as 'Not Provided' for the blanks rather than leaving nulls that break visuals.
MaritalStatusNone significant.None.
MonthlySalaryStored as three different things in the same column: a plain number, text with an 'NGN' prefix and thousands separators, and text with only thousands separators, plus a handful of missing values.Use Replace Values to strip 'NGN', spaces and commas, then Transform > Data Type > Decimal Number; handle blanks with Replace Errors or a business decision (exclude from average, or flag as Not Disclosed).
EmploymentStatusNone significant.None.

DAX Measures: Solutions

Create a dedicated table named Measures (a blank query with no rows) and place every measure below inside it, so measures are not scattered across fact tables.

Operations measures

TaskDAX solution
Create a measure for total tonnes produced across all plants and periods.
Total Tonnes Produced = SUM(Operations[QuantityProducedTonnes])
Create a measure for total downtime hours, making sure blank values are not treated as zero incorrectly if that would misstate the average.
Total Downtime Hours = SUM(Operations[DownTimeHours])
Create a measure for average downtime hours per production run.
Average Downtime Hours = AVERAGE(Operations[DownTimeHours])
Create a measure that calculates the percentage of output that was Grade A quality.
Percent Grade A = DIVIDE(CALCULATE(COUNTROWS(Operations), Operations[QualityGrade] = "Grade A"), COUNTROWS(Operations))

Supply Chain measures

TaskDAX solution
Create a measure for total tonnes dispatched.
Total Tonnes Dispatched = SUM("Supply Chain"[QuantityDispatchedTonnes])
Create a measure for the percentage of shipments delivered on time (status equals Delivered).
Percent Delivered = DIVIDE(CALCULATE(COUNTROWS("Supply Chain"), "Supply Chain"[DeliveryStatus] = "Delivered"), COUNTROWS("Supply Chain"))
Create a measure counting delayed or cancelled shipments.
Delayed Or Cancelled Shipments = CALCULATE(COUNTROWS("Supply Chain"), "Supply Chain"[DeliveryStatus] IN {"Delayed", "Cancelled"})

Legal measures

TaskDAX solution
Create a measure for the total claim amount across all open cases.
Total Open Claim Amount = CALCULATE(SUM(Legal[ClaimAmountNaira]), Legal[CaseStatus] IN {"Open", "Pending"})
Create a measure counting cases still open or pending.
Open Cases Count = CALCULATE(COUNTROWS(Legal), Legal[CaseStatus] IN {"Open", "Pending"})
Create a measure for average claim amount per case type.
Average Claim Per Case Type = AVERAGEX(VALUES(Legal[CaseType]), CALCULATE(AVERAGE(Legal[ClaimAmountNaira])))

Admin measures

TaskDAX solution
Create a measure for total cost of approved requests only.
Total Approved Cost = CALCULATE(SUM(Admin[CostNaira]), Admin[ApprovalStatus] = "Approved")
Create a measure for the count of pending requests awaiting approval.
Pending Requests Count = CALCULATE(COUNTROWS(Admin), Admin[ApprovalStatus] = "Pending")

Customer Service measures

TaskDAX solution
Create a measure for the average resolution time in days, excluding tickets with missing resolution days.
Average Resolution Days = AVERAGEX(FILTER("Customer Service", NOT ISBLANK("Customer Service"[ResolutionDays])), "Customer Service"[ResolutionDays])
Create a measure for the count of open or escalated tickets.
Open Or Escalated Tickets = CALCULATE(COUNTROWS("Customer Service"), "Customer Service"[TicketStatus] IN {"Open", "Escalated"})
Create a measure for total ticket volume.
Total Tickets = COUNTROWS("Customer Service")

I.T measures

TaskDAX solution
Create a measure for average resolution hours.
Average Resolution Hours = AVERAGEX(FILTER('I.T', NOT ISBLANK('I.T'[ResolutionHours])), 'I.T'[ResolutionHours])
Create a measure for the count of critical priority tickets.
Critical Tickets Count = CALCULATE(COUNTROWS('I.T'), 'I.T'[PriorityLevel] = "Critical")

Accounts and Finance measures

TaskDAX solution
Create a measure for total transaction value.
Total Transaction Value = SUM("Accounts and Finance"[Amount])
Create a measure for total value by transaction type, usable in a matrix or bar chart.
Total By Transaction Type = CALCULATE(SUM("Accounts and Finance"[Amount]), ALLEXCEPT("Accounts and Finance", "Accounts and Finance"[TransactionType]))
Create a measure for the count of failed payments.
Failed Payments Count = CALCULATE(COUNTROWS("Accounts and Finance"), "Accounts and Finance"[PaymentStatus] = "Failed")

Risk Management and Compliance measures

TaskDAX solution
Create a measure for the average compliance audit score, excluding invalid or missing scores.
Average Compliance Score = AVERAGEX(FILTER('Risk Mgmt and Compliance', 'Risk Mgmt and Compliance'[ComplianceAuditScore] <= 100 && NOT ISBLANK('Risk Mgmt and Compliance'[ComplianceAuditScore])), 'Risk Mgmt and Compliance'[ComplianceAuditScore])
Create a measure for the count of high or critical risks not yet mitigated.
High Risk Not Mitigated = CALCULATE(COUNTROWS('Risk Mgmt and Compliance'), 'Risk Mgmt and Compliance'[RiskLevel] IN {"High", "Critical"}, 'Risk Mgmt and Compliance'[MitigationStatus] <> "Mitigated")

Internal Control measures

TaskDAX solution
Create a measure for total findings across all audits.
Total Findings = SUM('Internal Control'[FindingsCount])
Create a measure for the count of audits still open or in review.
Open Or In Review Audits = CALCULATE(COUNTROWS('Internal Control'), 'Internal Control'[AuditStatus] IN {"Open", "In Review"})

Human Resources measures

TaskDAX solution
Create a measure for headcount of active employees only.
Active Headcount = CALCULATE(COUNTROWS("Employees (HR)"), "Employees (HR)"[EmploymentStatus] = "Active")
Create a measure for average monthly salary, excluding missing values.
Average Monthly Salary = AVERAGEX(FILTER("Employees (HR)", NOT ISBLANK("Employees (HR)"[MonthlySalary])), "Employees (HR)"[MonthlySalary])

Dashboard Build Solutions

Exact visual, field well, and formatting instructions for every chart on every page.

Executive Overview Dashboard

A single landing page giving Dangote Cement leadership a plant-wide snapshot across production, dispatch and finance.
  1. Insert four Card visuals bound to [Total Tonnes Produced], [Total Tonnes Dispatched], [Total Transaction Value] and [Active Headcount]; format numbers with thousands separators and the Naira symbol where relevant.
  2. Insert a Map visual, set Location to Plants[State] and Size (or Bubble Size) to [Total Tonnes Produced]; enable data labels.
  3. Insert a Line Chart with Calendar[Month] on the X axis and [Total Tonnes Produced] on the Y axis; add a trend line via Analytics pane.
  4. Insert Slicer visuals for Plants[PlantName], Plants[Region] and Calendar[Date], and sync them across every page using the Sync Slicers pane.

Operations and Production Performance Dashboard

Deep dive for plant managers into production output, downtime, and quality by plant and line.
  1. Clustered Column Chart: Axis Plants[PlantName], Value [Total Tonnes Produced].
  2. Line Chart: Axis Calendar[Date] (or Month), Value [Total Downtime Hours].
  3. Donut Chart: Legend Operations[QualityGrade], Value [Total Tonnes Produced], using Percent Grade A as a supporting card.
  4. Table visual: Columns Operations[MachineID] and [Total Downtime Hours], sorted descending, Top N filter applied to show the worst ten machines.

Supply Chain and Distribution Dashboard

Tracks dispatch volumes, delivery reliability, and distributor performance.
  1. Stacked Bar Chart: Axis "Supply Chain"[DestinationState], Value [Total Tonnes Dispatched].
  2. Gauge visual bound to [Percent Delivered], target set to 95 percent using a Target measure or a fixed value in Format pane.
  3. Bar Chart: Axis Distributors[DistributorName], Value [Total Tonnes Dispatched], sorted descending.
  4. Card visual bound to [Delayed Or Cancelled Shipments].

Customer Service Dashboard

Monitors complaint volume, resolution speed, and complaint categories to support service improvement.
  1. Two Card visuals bound to [Total Tickets] and [Average Resolution Days].
  2. Column Chart: Axis "Customer Service"[ComplaintCategory], Value [Total Tickets].
  3. Line Chart: Axis Calendar[Month], Value [Total Tickets].
  4. Table visual: Columns Employees[FullName], [Total Tickets], [Average Resolution Days], sorted by ticket count descending.

Legal and Compliance Risk Dashboard

Gives Legal, Risk and Internal Control a shared view of exposure, open cases, and audit findings.
  1. Card visual bound to [Total Open Claim Amount].
  2. Matrix visual: Rows Legal[CaseType], Columns Legal[CaseStatus], Values COUNTROWS(Legal) and [Total Open Claim Amount].
  3. Bar Chart: Axis 'Risk Mgmt and Compliance'[RiskLevel], Legend [MitigationStatus], Value COUNTROWS('Risk Mgmt and Compliance').
  4. Column Chart: Axis 'Internal Control'[DepartmentAudited], Value [Total Findings].

Finance and Accounts Dashboard

Summarises transaction volumes, values and payment status across the business.
  1. Card visual bound to [Total Transaction Value].
  2. Pie Chart: Legend "Accounts and Finance"[TransactionType], Value [Total Transaction Value].
  3. Column Chart: Axis Plants[PlantName], Value [Total Transaction Value].
  4. Card visual bound to [Failed Payments Count].

Human Resources and Admin Dashboard

Gives HR and Admin a combined view of headcount, department mix, and admin request cost.
  1. Two Card visuals bound to [Active Headcount] and [Average Monthly Salary].
  2. Bar Chart: Axis "Employees (HR)"[Department], Value [Active Headcount].
  3. Donut Chart: Legend "Employees (HR)"[EmploymentStatus], Value COUNTROWS("Employees (HR)").
  4. Column Chart: Axis Admin[AssetType], Value [Total Approved Cost].
