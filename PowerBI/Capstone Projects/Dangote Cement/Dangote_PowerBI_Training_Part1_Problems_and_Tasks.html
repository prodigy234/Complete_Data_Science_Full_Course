1. How to Use This Training

Read this before opening the Excel workbook.

The dataset: Dangote_Cement_PowerBI_Training_Dataset.xlsx contains 12 sheets covering every department of the business: Plants and Distributors (reference tables), Employees (Human Resources), Operations, Supply Chain, Legal, Admin, Customer Service, I.T, Accounts and Finance, Risk Management and Compliance, and Internal Control.

The task for the learner: for each sheet, import the data into Power Query, apply the cleaning tasks listed below column by column, load the cleaned tables into the Power BI data model, build the relationships listed in the data model section, write the DAX measures listed in the DAX section, and build the dashboard pages described in the dashboards section.

A note on hyphens: all training materials in this set use the standard keyboard hyphen only.

DAX Measures: Tasks

For each topic below, create the requested measures in a dedicated Measures table in Power BI. Do not hardcode numbers; every measure must recalculate as filters change.

Operations measures

  • Create a measure for total tonnes produced across all plants and periods.
  • Create a measure for total downtime hours, making sure blank values are not treated as zero incorrectly if that would misstate the average.
  • Create a measure for average downtime hours per production run.
  • Create a measure that calculates the percentage of output that was Grade A quality.

Supply Chain measures

  • Create a measure for total tonnes dispatched.
  • Create a measure for the percentage of shipments delivered on time (status equals Delivered).
  • Create a measure counting delayed or cancelled shipments.

Legal measures

  • Create a measure for the total claim amount across all open cases.
  • Create a measure counting cases still open or pending.
  • Create a measure for average claim amount per case type.

Admin measures

  • Create a measure for total cost of approved requests only.
  • Create a measure for the count of pending requests awaiting approval.

Customer Service measures

  • Create a measure for the average resolution time in days, excluding tickets with missing resolution days.
  • Create a measure for the count of open or escalated tickets.
  • Create a measure for total ticket volume.

I.T measures

  • Create a measure for average resolution hours.
  • Create a measure for the count of critical priority tickets.

Accounts and Finance measures

  • Create a measure for total transaction value.
  • Create a measure for total value by transaction type, usable in a matrix or bar chart.
  • Create a measure for the count of failed payments.

Risk Management and Compliance measures

  • Create a measure for the average compliance audit score, excluding invalid or missing scores.
  • Create a measure for the count of high or critical risks not yet mitigated.

Internal Control measures

  • Create a measure for total findings across all audits.
  • Create a measure for the count of audits still open or in review.

Human Resources measures

  • Create a measure for headcount of active employees only.
  • Create a measure for average monthly salary, excluding missing values.

Dashboards to Build

Build one Power BI report page for each dashboard below, using the title given. Every visual must be built from the cleaned tables and the DAX measures created earlier, never from hardcoded values.

Executive Overview Dashboard

A single landing page giving Dangote Cement leadership a plant-wide snapshot across production, dispatch and finance.
  1. A set of KPI cards for Total Tonnes Produced, Total Tonnes Dispatched, Total Transaction Value, and Active Headcount.
  2. A map or filled map visual of Nigeria showing production volume by plant location.
  3. A trend line chart of monthly tonnes produced over the two year period.
  4. A slicer panel for Plant, Region and Date so the whole page can be filtered together.

Operations and Production Performance Dashboard

Deep dive for plant managers into production output, downtime, and quality by plant and line.
  1. A clustered column chart of tonnes produced by plant.
  2. A line chart of downtime hours trend over time.
  3. A donut chart of output split by quality grade.
  4. A table listing top machines by downtime hours.

Supply Chain and Distribution Dashboard

Tracks dispatch volumes, delivery reliability, and distributor performance.
  1. A stacked bar chart of tonnes dispatched by destination state.
  2. A gauge visual for percentage of shipments delivered on time.
  3. A bar chart ranking distributors by tonnes received.
  4. A card showing the count of delayed or cancelled shipments.

Customer Service Dashboard

Monitors complaint volume, resolution speed, and complaint categories to support service improvement.
  1. A card for total tickets and a card for average resolution days.
  2. A column chart of tickets by complaint category.
  3. A line chart of ticket volume trend by month.
  4. A table of agents with the highest ticket counts and average resolution time.

Legal and Compliance Risk Dashboard

Gives Legal, Risk and Internal Control a shared view of exposure, open cases, and audit findings.
  1. A card for total open claim amount.
  2. A matrix of case count and claim amount by case type and status.
  3. A bar chart of risk count by risk level, split by mitigation status.
  4. A column chart of audit findings by department audited.

Finance and Accounts Dashboard

Summarises transaction volumes, values and payment status across the business.
  1. A card for total transaction value.
  2. A pie chart of transaction value by transaction type.
  3. A column chart of transaction value by plant.
  4. A card for count of failed payments requiring follow up.

Human Resources and Admin Dashboard

Gives HR and Admin a combined view of headcount, department mix, and admin request cost.
  1. A card for active headcount and average monthly salary.
  2. A bar chart of headcount by department.
  3. A donut chart of employment status split.
  4. A column chart of approved admin request cost by asset type.
