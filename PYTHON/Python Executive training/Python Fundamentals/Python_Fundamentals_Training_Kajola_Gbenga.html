Section 1: Python Data Types

Every value in Python has a data type. A data type tells Python what kind of value is being stored and what operations can be performed on it. Python is dynamically typed, which means you do not need to declare the type of a variable before using it - Python figures it out automatically based on the value you assign. Python is also strongly typed, which means it will not silently convert between unrelated types (for example, adding a string to an integer will raise an error instead of guessing what you meant).

In this section we cover every core built in data type: integers, floating point numbers, complex numbers, booleans, strings, and the special value None. We also cover how to check a type, and how to convert (cast) one type into another.

1.1 Checking a Type with type()

Before learning individual types, it helps to know how to inspect the type of any value. Python gives us the built in type() function for this purpose. Every single value that exists in Python, including numbers, text, functions, and even classes, has a type that Python can report back to you.

age = 30
print(type(age))

name = "Kajola"
print(type(name))

is_active = True
print(type(is_active))

nothing = None
print(type(nothing))

<class 'str'>
<class 'bool'>

Notes & Tips
  • type() always returns a class object, shown as <class 'typename'>.
  • Use isinstance(value, SomeType) instead of type(value) == SomeType when you also want to correctly handle subclasses.

An integer is a whole number, positive, negative, or zero, with no decimal point. Python integers have unlimited precision, meaning they can grow as large as your computer's memory allows, unlike many other languages where integers overflow after a fixed number of bits.

Section 2: Python Data Structures

Data structures are containers that hold multiple values together in an organized way. Python ships with four core built in data structures: lists, tuples, sets, and dictionaries. Choosing the right one depends on whether you need order, whether the collection should be changeable (mutable), and whether duplicate values are allowed.

Section 3: Conditional Statements (If Else)

Conditional statements let a program make decisions and execute different blocks of code depending on whether certain conditions are True or False. Python uses the keywords if, elif (short for else if), and else, combined with indentation (whitespace) to define which code belongs to which branch, instead of curly braces used by many other languages.

Section 4: Loops

Loops let you repeat a block of code multiple times, either a set number of times, or until a condition is no longer True. Python provides two loop constructs: the for loop, used to iterate over a known sequence or iterable, and the while loop, used to repeat while a condition remains True.

Functions let you avoid repeating yourself, organize code into logical pieces, and make programs easier to test and reason about.

5.8 Recursion

A recursive function is a function that calls itself in order to solve a smaller version of the same problem. Every recursive function needs a base case, a condition under which it stops calling itself, to avoid running forever.

    if n == 0:
        print("Liftoff!")
        return

    countdown(n - 1)

  • Recursion is elegant for problems that are naturally self similar, such as factorials, tree traversal, and certain search algorithms, but a simple loop is often more efficient in Python.

Section 6: The Match Statement (Structural Pattern Matching)

Introduced in Python 3.10, the match statement provides structural pattern matching: a more powerful and readable alternative to long if/elif/else chains for certain kinds of decisions. match compares a subject value against a series of case patterns, running the code under the first pattern that matches. Beyond matching simple literal values, match can also match and unpack the shape of sequences, mappings, and objects.

6.1 Basic match / case with Literal Values

The simplest form of match compares a subject against literal values, similar to a switch statement found in other languages, but written using Python's own syntax and indentation rules.

  • Cases are checked top to bottom, and only the first matching case runs, exactly like elif chains.

6.3 Capturing Values and Using Guards (case ... if)

A case pattern can bind part of the subject to a new variable name, which is then usable inside that case's body. A guard is an additional if condition attached to a case, which must also be True for that case to be chosen, giving you conditional matching beyond simple equality.

            return f"Positive even number: {value}"
        case value:
            return f"Positive odd number: {value}"

print(describe_number(-7))
print(describe_number(8))

  • Guards (the if part) let you express conditions that plain pattern matching alone cannot, such as comparisons or arbitrary boolean expressions.

# Use match when:
#   - you are comparing one subject against many possible exact shapes or values

#   - you have many literal cases, improving readability over a long elif chain
