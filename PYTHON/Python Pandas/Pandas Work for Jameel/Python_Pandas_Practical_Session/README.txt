FOLDER CONTENTS
  Python_Pandas_Practical_Session.ipynb   The notebook (27 sections + capstone + solutions)
  pandas_datasets/                         16 practice datasets (CSV, Excel, JSON, Parquet, SQLite, HTML)
  generate_datasets.py                     Recreates every dataset (python generate_datasets.py)

HOW TO RUN
  1. Install:   pip install pandas numpy openpyxl xlrd pyarrow sqlalchemy lxml matplotlib jupyter
  2. Keep the notebook and the pandas_datasets folder side by side (as shipped).
  3. Open the notebook in Jupyter or VS Code and run all cells from the top.
  4. Results you export are written to a new folder called pandas_outputs.

NOTES
  - Tested end to end on pandas 3.0.6 and pandas 2.2.3 (0 errors, 0 warnings on both).
  - All data is synthetic and was created for training purposes only.
